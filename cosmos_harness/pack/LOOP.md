# Loop law

Turn cap 8. A failed grade is not cleared. The latch is not cleared on the
next turn or on a token-budget continuation. The pin does not change
mid-turn. A sample whose model is not the pin is PIN_SWAP. There is no
fallback model.

Oracle fails before an edit and passes after. Mutations wait on oracle_red.

Done is five hashes. A green sentence is not a DoneBundle.

4Cs run before a coding seat is called a pass: py_compile, ruff, mypy, pytest.
A missing checker is UNAVAILABLE and blocks.

live/ is refused.

One scar maps to one SOP. The same scar does not fire twice.

Eight hooks run in order: prompt_in, prompt_bound, pre_tool, post_tool, stop,
seat_scar, verify, done. The model sample is the only unbound step.

Eight layers: l1_role, l2_model, l3_harness, l4_wrapper, l5_skills, l6_tools,
l7_enviro, l8_mission.

delete is not a hand. The host records NOT_A_HAND and holds the latch.
Hands are read, glob, grep, edit, write, archive, oracle, worktree.
