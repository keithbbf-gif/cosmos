# SLP WOW — staging package

Professional community hub for speech-language pathologists: news, resources, word lists, and a forum placeholder. **Audience is clinicians—not patients.** Clinical marketing for WOW Therapies lives in `../wowtherapies/`.

## Theme choice

This package ships a **GeneratePress child theme** for straightforward MochaHost deployment. An optional **Eleventy → WordPress hybrid** workflow is documented in `DEPLOY.md` for static prototypes; production push defaults to GP child + block editor content.
