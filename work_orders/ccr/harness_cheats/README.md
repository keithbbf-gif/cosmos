# Harness cheats — majors, for now

COSMOS CODE is the coding rail. These cards are how a HERO pack binds to it
and to each major door. A card is not an applied pack.

**Applied** = the chosen door bound each layer and the reply obeyed it.
A written file is not a pass. `require_duds` is the outfit check, not the pass.

Pack weight follows the door (`PACK_BY_HARNESS.md`). Overlap is on purpose:
a strong door gets a thin pack; a weak or missing door gets the layers it
did not bind. Same agent, different outfit.
