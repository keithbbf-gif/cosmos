- **Binary:** `pi.cmd -p` (not `pi.ps1` — execution policy blocks it).
- **Model:** `--provider zai --model glm-5.3-flash`. Fallback `--provider openrouter --model z-ai/glm-5.3-flash` only if Z.AI is unbound.
- **Home:** `PI_CODING_AGENT_DIR=V:\A\Ai\COSMOS\live\work\pi-home`.
- **Tools:** `--tools read,write,edit`. Built-ins exist; the flag is the pool. `--no-tools` is a ping, not a coder pass.
- **Wrapper:** `--system-prompt` is `WRAP.md` bytes when the pack has it. Do not add a second system sentence for skills.
- **Writes:** cwd is the worktree. Grade reads files after the process exits. `mouth.txt` is not the check.
- **COSMOS CODE:** PathJail on any host harvest. Pi does not replace hooks-as-law.
