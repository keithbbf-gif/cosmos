# Field note — thin base (not a source review)

Keith pasted practitioner comments, 2026-09-25. Not measured here. Not a
license to clone any of these trees.

## Take

- A copy of Claude Code is the wrong aim. Unused tools and prompt pack in
  context tax every call. Worse on open and local models, which were not
  trained on that pack.
- Peak shape is a minimal base plus the features this job needs. That is
  `PACK_BY_HARNESS.md`: thin pack on a strong door, fat pack only where the
  door did not bind the layer.
- Pi is the reference for that minimal door. It is not a Claude Code
  replacement. Guardrails and plan/edit are extensions, not defaults.
- Plan vs edit still matters for weaker models. Keep it as a mode. Do not
  drop it because a maximalist harness made it optional.
- OpenCode is the fatter OSS door (plan/build, subagents if configured).
  Qwen Code is the lighter cousin. Neither is the product.
- Hermes is a general agent framework. Coding through OpenCode is one tool.
  It is not COSMOS CODE. Same split we already have: HARNESS plane vs CODE.
- DeepSeek: everything is a plugin. That is their door (`dsh`), not our loop.
- Kilo is a Cursor-class seat. Cursor stays Gitur BUILD only.
