Laws

One law per row, with the corrective move beside it. Laws are blunt so they survive a busy shift.

File Integrity and The Truncated Command Ledger

Law: An unmeasured file write is an assumed corruption.

Instead

Verify file size and inspect tails immediately after every edit.

Connector Drift and The Compliant Node That Wrote Nothing

Law: Never accept an agent self-report of external write authority.

Instead

Confirm every write through an independent round-trip readback.

Filesystem Mounts and The Disappearing Colon

Law: A filesystem mount can corrupt byte streams without breaking transport.

Instead

Hash and compare critical files directly against host disk before execution.

Buffer Limits and Eaten at the Letter G

Law: Unchecked truncation presents identically to clean completion.

Instead

Enforce explicit pre- and post-generation item counts on every output collection.

Local Infrastructure and The Static Ghost Dashboard

Law: Serving markup is not serving an application.

Instead

Probe API endpoints with live requests during startup verification.

Tool Discovery and Rebuilding the Wheel in the Dark

Law: An unindexed utility does not exist to an agent.

Instead

Query an explicit tools index before writing new infrastructure.

Deployment Verification and A Two-Hundred for Stale Bytes

Law: A successful response code is not evidence of a fresh deployment.

Instead

Diff payload content or release hashes against the upstream source.

Hallucination and A Real Identifier for an Imaginary Paper

Law: A resolvable DOI does not validate the claim wrapped around it.

Instead

Pull and compare publication metadata against the returned claim before citing.

Bibliographic Verification and The Hundred-Percent Failure Run

Law: Unverified citation generation yields complete bibliographic drift.

Instead

Gate every literature pass through an external citation validator.

Test Suite Blindspots and Green Tests on an Omitted Voltage

Law: A green test suite only proves you tested what you remembered to question.

Instead

Benchmark physical equations against known analytical ground truth and outside review.

Multi-Agent Consensus and The Fabricated Consensus

Law: Multi-agent consensus claims can be synthesized out of whole cloth.

Instead

Verify inter-agent agreement directly from raw transcripts.

Cross-Platform I/O and The Carriage Return Integrity Trap

Law: Sandboxes that ignore host newline translations create false confidence.

Instead

Open files in binary mode whenever enforcing byte-level integrity.
