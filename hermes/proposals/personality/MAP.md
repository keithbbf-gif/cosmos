# personality

Hermes keeps the agent's identity in `SOUL.md` under `HERMES_HOME`, not the working directory. That file is slot 1 of the system prompt. Hermes seeds a starter file once and does not overwrite an existing file. Hermes itself falls back when a soul file is empty or unloadable. This proposal does not substitute an identity. An empty or whitespace-only persona raises `EMPTY`. The caller passes `FALLBACK_SOUL` when the home file is missing. The text is scanned and size-limited before it becomes the prefix, and it is not copied again into the context-file block. `/personality` selects a session overlay. Built-in names are `helpful`, `concise`, `technical`, `creative`, `teacher`, `kawaii`, `catgirl`, `pirate`, `shakespeare`, `surfer`, `noir`, `uwu`, `philosopher`, and `hype`. `none`, `default`, and `neutral` clear the overlay. A custom catalog, Hermes `agent.personalities`, adds a name or replaces a built-in of the same name. The selection is a name. It does not write the manual system prompt, and it is not the terminal skin.

The live seam is SOUL first. No COSMOS module owns soul text and the session preset.

`assemble(soul, style)` returns the soul text first and the style line second, with a blank line between them when the style has content. It does not resolve preset names. An empty soul refuses. A blank style line means no second block. `open_session` freezes the resolved soul, its sha256, the active preset, the catalog, and the recorded cap. `swap_preset` replaces the preset and copies the soul sha256 unchanged. `prompt` returns that same order under the session cap. `prefix` freezes that block: soul text, one style line, the soul sha256, and the cap. `list_presets` lists `none`, then the built-ins, then catalog-only names. `records` emits the session. `rebuild` from those records returns an equal session, and `prefix` of that session matches. A `Preset` passed to `swap_preset` is an overlay for this session and is not added to the catalog. A stored name that is neither built-in nor in the catalog keeps the supplied text. A stored name that is known must match that text. This module does not read or write a home directory.

Authority for the soul text sits with the human who supplies it. Authority for the active preset sits with the session record. The record is in-memory. It is not a ledger append and not a projection file. There is no retry class.

The policy cap is 8000 characters on the assembled text. A requested cap above 8000 is ignored and 8000 is recorded. A lower positive cap is recorded and enforced. Text past the cap is `OVERSIZE`. The module does not truncate. Refusal codes: `BAD_LIMIT`, `BAD_NAME`, `BAD_PRESET`, `BAD_SCHEMA`, `BAD_SESSION`, `CATALOG_CAP`, `DUP_NAME`, `EMPTY`, `GUARD_ESCAPE`, `HASH_MISMATCH`, `INVISIBLE`, `NOT_INT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `SECRET`, `UNKNOWN_PRESET`. Soul or style text that contains `disable approval`, `yolo`, or `no restrictions`, ignoring case and interior whitespace, raises `GUARD_ESCAPE`, including when the phrase is split across the soul and the style line. There is no off switch and no yolo mode. Secret-shaped text raises `SECRET`. Bidi, zero-width, and other invisible characters raise `INVISIBLE`. An unknown preset name raises `UNKNOWN_PRESET`.

CCr would land this later by feeding `prompt` into the identity slot and keeping the preset as a session overlay behind that soul. The soul hash stays fixed when the preset changes, so a gate review can see that the identity did not move. Text that tries to disable approval never reaches the gate. An empty persona never becomes a substituted identity. The landing still would not write `SOUL.md` and would not raise the 8000 cap.

## Ship

- operations: `BUILTIN_NAMES`, `CATALOG_CAP`, `FALLBACK_SOUL`, `NAME_LIMIT`, `SCHEMA`, `TOTAL_CAP`, `Prefix`, `Preset`, `Record`, `Records`, `Session`, `assemble`, `list_presets`, `open_session`, `prefix`, `prompt`, `rebuild`, `records`, `swap_preset`
- refusal codes: `BAD_LIMIT`, `BAD_NAME`, `BAD_PRESET`, `BAD_SCHEMA`, `BAD_SESSION`, `CATALOG_CAP`, `DUP_NAME`, `EMPTY`, `GUARD_ESCAPE`, `HASH_MISMATCH`, `INVISIBLE`, `NOT_INT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `SECRET`, `UNKNOWN_PRESET`
- what this module still refuses to execute: reading or writing `SOUL.md`, seeding a home directory, editing a manual system prompt, changing the terminal skin, truncating persona text, raising the 8000 cap, opening a socket, and injecting any phrase that disables approval
- hot-path shape: one pass builds a dict of catalog names; each block is bounded and scanned once; the length check is the sum of the two blocks before the one concatenation; an overlay that does not fit raises `OVERSIZE` and leaves the previous session unchanged, so a later shorter overlay can still be selected
