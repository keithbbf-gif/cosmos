# spotify

Hermes Spotify is an opt-in toolset for playback, devices, queue, search, playlists, albums, and the saved library. It stays off until a person enables it. Playback changes need Spotify Premium and, when a later service runs them, an active Connect device. Search, playlists, albums, library, and the read-only playback actions do not change what is playing. OAuth tokens stay in the product auth file. A 401 refresh retries once in that product client. This proposal does not open that client.

This proposal is a new seam. The live COSMOS tree has no Spotify module. The live seam stays off until enabled. This module does not open a socket, does not read a clock, and does not keep a token field.

`Spotify` starts disabled. `enable(credential_id, tier="unverified", now=...)` arms it. The id is a vault handle such as `cred-music`. A raw `sk-`, `Bearer`, or `api_key=` value raises `SECRET`. There is no off switch and no `yolo`. A second id or a different tier raises `CRED_LOCKED`. `play(track_id)` returns a frozen `Play` for one 22-character track id or a `spotify:track:` URI. `executes` is false. `pause`, `search`, and `act` return a frozen `Action` for the other tool actions. `pack` keeps catalog titles that fit a character budget and skips a title that does not, including a later shorter title. `note_failure` records one confirming retry for `HTTP_401` and refuses a second. `classify_status` names 204, 401, 403, and 429. Any other status is `UNCLASSIFIED`. `run` raises `NOT_RUN`.

A caller cap above 200, a page limit above 50, or a batch above 20 is ignored. The descriptor records the policy cap. Bool is not an int. The only clock is `now`. A timestamp that does not move forward raises `STALE`. `records` is a hash chain. `rebuild` of those rows returns the same `snapshot`.

Authority is human. Enabling the toolset is an explicit opt-in, and the credential id is the only secret handle. The descriptor is not a playback call. This module does not write a ledger file, a projection database, or an attempt workspace.

Refusal codes: `DISABLED`, `SECRET`, `MISSING_CREDENTIAL`, `BAD_CREDENTIAL`, `CRED_LOCKED`, `BAD_TIER`, `BAD_TRACK`, `BAD_ID`, `BAD_DEVICE`, `BAD_TOOL`, `BAD_ACTION`, `BAD_TYPE`, `BAD_MARKET`, `BAD_FLAG`, `BAD_TEXT`, `BAD_ITEMS`, `EMPTY`, `PREMIUM`, `DUPLICATE`, `STALE`, `BAD_SCHEMA`, `BAD_CAP`, `BAD_PLAN`, `BAD_RECORD`, `CHAIN`, `NOT_RUN`, `NOT_RETRYABLE`, `RETRY_SPENT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, `OUT_OF_RANGE`, `UNCLASSIFIED`, `MISSING_DEVICE`, `MISSING_SUBJECT`, `UNEXPECTED`.

CCr would land this by binding the harness Spotify tools to `enable` and the descriptor methods after the human supplies a credential id. The tool returns the frozen descriptor. A later approved rail performs the catalog or playback call, enforces Premium and an active device for mutating playback, and may retry one named 401 refresh. That landing adds no HTTP client and no token field here.

## Ship

- Operations: `BATCH_CAP`, `CHAR_BUDGET`, `CRED_CAP`, `DEVICE_CAP`, `GENESIS`, `ID_CAP`, `INPUT_CAP`, `OFFSET_MAX`, `PAGE_CAP`, `POSITION_MAX`, `QUERY_CAP`, `RETRY_CLASS`, `ROW_CAP`, `SCHEMA`, `SEARCH_TYPES`, `TOOLS`, `VOLUME_MAX`, `Action`, `Note`, `Packed`, `Play`, `Row`, `Snapshot`, `Spotify`, `classify_status`, `rebuild`, `run`. `Spotify` methods are `enable`, `play`, `pause`, `search`, `act`, `pack`, `note_failure`, `records`, `snapshot`, plus `enabled`, `credential_id`, and `tier`.
- Refusal codes: `DISABLED`, `SECRET`, `MISSING_CREDENTIAL`, `BAD_CREDENTIAL`, `CRED_LOCKED`, `BAD_TIER`, `BAD_TRACK`, `BAD_ID`, `BAD_DEVICE`, `BAD_TOOL`, `BAD_ACTION`, `BAD_TYPE`, `BAD_MARKET`, `BAD_FLAG`, `BAD_TEXT`, `BAD_ITEMS`, `EMPTY`, `PREMIUM`, `DUPLICATE`, `STALE`, `BAD_SCHEMA`, `BAD_CAP`, `BAD_PLAN`, `BAD_RECORD`, `CHAIN`, `NOT_RUN`, `NOT_RETRYABLE`, `RETRY_SPENT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, `OUT_OF_RANGE`, `UNCLASSIFIED`, `MISSING_DEVICE`, `MISSING_SUBJECT`, `UNEXPECTED`.
- This module still refuses to play audio, open a socket, start an OAuth listener, refresh a token, read the auth file, call the Spotify Web API, or schedule cron. `run` is `NOT_RUN`. `note_failure` records one `HTTP_401` retry and does not perform it. A free tier cannot plan a playback mutation. An unverified tier can plan one, and the plan still does not execute.
- Hot-path shape: one spec-dict lookup, then one pass. Batch ids that do not fit the remaining count are skipped and later ids are still checked. `pack` skips a title larger than the remaining character budget and keeps a later title that fits. A higher caller cap is ignored. One sha256 links each committed row. Credential ids compare with `const_eq`.
