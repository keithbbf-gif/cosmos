# Language packs

Hermes translates static UI text from plugin packs, a profile overlay, and bundled catalogs. Lookup checks the plugin layer, then the overlay, then bundled. The last plugin loaded wins. A pack may be partial. Stock Hermes then walks those three layers in English and otherwise shows the raw key. Agent replies, tool output, and slash-command names stay as written. A pack names an id, an endonym, and an optional right-to-left flag. Core strings keep named placeholders such as `{count}`. TUI and desktop strings keep positional placeholders such as `{0}`. A placeholder set that differs from the winning English phrase for that key and surface is not shown. Values are text. The segments `on`, `off`, `yes`, and `no` are not keys. `HERMES_LANGUAGE` overrides `display.language`. Installing a pack from a URL is a host action.

The live seam is missing key is MISSING. No COSMOS module stores UI catalogs. A missing key raises `MISSING`. It does not return an empty string and it does not return the raw key. Fallback to another language is `fallback`: one step onto one named locale, and the hit records `source`, `status`, and `step`. A list or tuple of locales is a chain and raises `BAD_FALLBACK`. The same locale is not a fallback.

`add(locale, table)` records one surface (`core`, `tui`, or `desktop`) and one layer (`plugin`, `overlay`, or `bundled`) on a frozen `Catalog`. Nested mappings flatten to dotted keys. The locale matches `^[a-z]{2}(-[A-Z]{2})?$`. Any other tag is `BAD_LOCALE`. A later `add` for the same locale, surface, layer, and key replaces that phrase. A later `add` for that locale also replaces the endonym and the rtl flag. Plugin outranks overlay. Overlay outranks bundled. `lookup(locale, key)` returns a `LookupHit` with status `HIT`, `step` 0, and `source` equal to the asked locale. An unknown locale raises `BAD_LOCALE`. `fallback(locale, key, catalog, onto)` returns that same hit when the asked locale has the key. Otherwise it reads `onto` once and returns status `FALLBACK`, `step` 1, and `source` equal to `onto`. A third locale is not read. Both locales must already be registered. `rebuild` replays the locales and phrases into an equal catalog. `choose` returns a `LanguageChoice`. A non-empty `env` overrides the display locale. `languages` lists registered ids in first-add order. `fetch` raises `NO_FETCH`. Each locale surface holds at most `TABLE_CAP` phrases (256) across layers. `LOCALE_CAP` is 32. `VALUE_CAP` is 4000. `STEP_CAP` is 1. A requested cap above those values is ignored. The catalog and the hit record the policy caps.

Authority for the wording sits with the human who supplies the table. The catalog is a projection of those tables. `choose` returns a descriptor. It does not write a setting and it does not start a process.

Refusal codes: `BAD_LOCALE`, `BAD_KEY`, `BAD_TABLE`, `BAD_SURFACE`, `BAD_LAYER`, `BAD_FLAG`, `BAD_PLACEHOLDER`, `BAD_CATALOG`, `BAD_SCHEMA`, `BAD_STATUS`, `BAD_SOURCE`, `BAD_RECORD`, `BAD_LIMIT`, `BAD_FALLBACK`, `NOT_TEXT`, `NULL_BYTE`, `EMPTY`, `OVERSIZE`, `OVER_CAP`, `DUPLICATE`, `SECRET`, `MISSING`, `NO_FETCH`.

CCr would parse a pack that is already on disk, call `add` for each surface, and read strings with `lookup`. A UI that wants English after a miss calls `fallback` once and keeps the hit. Download, YAML parsing, and plugin install stay outside this package. `fetch` remains a refusal.

## Ship

- operations: `DEPTH_CAP`, `ENDONYM_CAP`, `KEY_CAP`, `LAYERS`, `LOCALE_CAP`, `SCHEMA`, `STEP_CAP`, `SURFACES`, `TABLE_CAP`, `VALUE_CAP`, `Catalog`, `LanguageChoice`, `LocaleMeta`, `LookupHit`, `Phrase`, `add`, `choose`, `fallback`, `fetch`, `languages`, `lookup`, `rebuild`
- refusal codes: `BAD_CATALOG`, `BAD_FALLBACK`, `BAD_FLAG`, `BAD_KEY`, `BAD_LAYER`, `BAD_LIMIT`, `BAD_LOCALE`, `BAD_PLACEHOLDER`, `BAD_RECORD`, `BAD_SCHEMA`, `BAD_SOURCE`, `BAD_STATUS`, `BAD_SURFACE`, `BAD_TABLE`, `DUPLICATE`, `EMPTY`, `MISSING`, `NO_FETCH`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `OVER_CAP`, `SECRET`
- what this module still refuses to execute: pack download, YAML load, plugin install, writing `display.language`, a network call, a silent walk to English, a fallback chain, and a miss rendered as an empty string or as the raw key. `choose` is a descriptor. It does not start a process.
- hot-path shape: one dict probe on `(locale, surface, key)`. Layer rank is fixed when the catalog is built, so lookup does not scan phrases. `fallback` probes the asked locale and, only on a miss, probes one named locale. It does not walk a third locale.
