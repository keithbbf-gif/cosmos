# skins

Hermes skins change how the CLI looks. Personality stays a separate choice. `/skin` lists names and shows the active skin. `/skin <name>` switches the session immediately. A file under the user skins directory is a custom skin. Missing custom keys inherit from the built-in `default` skin. A user skin with the same name wins over the built-in. Hermes falls back to `default` when the name is unknown. A session switch does not write config. The durable choice is `display.skin`. Built-in names are `default`, `ares`, `mono`, `slate`, `daylight`, `warm-lightmode`, `poseidon`, `sisyphus`, and `charizard`. Hermes also stores colors, spinner face lists, branding strings, a tool prefix, tool emoji, banner art, and GUI CSS.

The live seam is terminal-safe text. No COSMOS module owns skin text. This proposal does not read a terminal.

`define` stores one skin. The fields are `banner`, `spinner`, `label`, and `prefix`. Each supplied field is bounded at 80 characters. A longer field raises `OVERSIZE`. A requested cap above 80 is ignored and 80 is recorded. A lower positive cap is recorded and then enforced. NUL is refused. Every other C0 control, DEL, every C1 control, the line separators `U+2028` and `U+2029`, and the bidi overrides `U+202A` through `U+202E` and `U+2066` through `U+2069` are stripped. A banner whose length is zero after that strip raises `BAD_SKIN`. Spinner, label, and prefix may be empty. A name is lowercase letters, digits, and single hyphens, and a control in a name is refused rather than rewritten. `builtin_skins` returns the nine built-in records in documented order. `pick` selects a session skin. A custom row with the same name wins. An unknown name raises `UNKNOWN` and does not fall back. `catalog` lists built-in names, then custom-only names in caller order. At most 80 custom rows are accepted. `render` builds one status line from the label, banner, spinner, and the caller session, card, note, and light. The only policy is `plain`, so the line contains no ANSI escape. The skin prefix separates segments, or one space when the prefix is empty. A segment that does not fit the remaining line budget is skipped, and a later segment that fits is still taken. An empty line after that pack is `BAD_SKIN`. A line that becomes secret-shaped only after the join is `SECRET`. `snapshot` freezes the custom rows. `rebuild` from that snapshot returns the same catalog. `hold` returns a descriptor that tells a human to set `display.skin`. The call writes nothing.

Authority to keep a default skin sits with the human. The session pick is an in-memory record. It is not a ledger append and not a projection file.

Refusal codes: `BAD_LIMIT`, `BAD_NAME`, `BAD_ORIGIN`, `BAD_POLICY`, `BAD_SCHEMA`, `BAD_SKIN`, `DUPLICATE`, `NOT_INT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `OVER_COUNT`, `SECRET`, `UNKNOWN`.

CCr would land this later as the terminal-text gate in front of the CLI skin picker. A loader outside this module would turn a skin file into the four strings and call `define`. `pick` would feed the session renderer. `render` would supply the plain status line. `hold` would stay a human action that writes `display.skin`. The policy cap stays 80. Unknown names stay refused. ANSI painting, CSS, and terminal reads stay outside this module.

## Ship

- operations: `CUSTOM_CAP`, `FIELD_CAP`, `SCHEMA`, `Catalog`, `Hold`, `Pick`, `Skin`, `Snapshot`, `Status`, `builtin_skins`, `catalog`, `define`, `hold`, `pick`, `rebuild`, `render`, `snapshot`
- refusal codes: `BAD_LIMIT`, `BAD_NAME`, `BAD_ORIGIN`, `BAD_POLICY`, `BAD_SCHEMA`, `BAD_SKIN`, `DUPLICATE`, `NOT_INT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `OVER_COUNT`, `SECRET`, `UNKNOWN`
- what this module still refuses to execute: reading a terminal or a skin file, writing `display.skin`, emitting ANSI, injecting `customCSS`, painting a GUI, and falling back to `default` when the name is unknown. `hold` and `render` return records and do not touch a screen.
- hot-path shape: one pass over custom rows into a set; builtin lookup is a dict; the status line is one left-to-right pack that skips a segment over the remaining budget and still takes a later segment that fits. Secret text is classified once on each field after controls are stripped, then once on the joined line.
