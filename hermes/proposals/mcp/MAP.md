# MCP client

Hermes connects to external MCP servers over stdio or HTTP, discovers tools at startup, and registers them under `mcp_<server>_<tool>`. Per-server include and exclude lists narrow that set. Include entries and exclude entries may be exact names or globs. Resource and prompt utility wrappers appear only when the config allows them and the server advertises the capability. Sampling (`sampling/createMessage`) and form elicitation ask Hermes for a model call or for structured user input. URL elicitation is declined. Tool text drops invisible Unicode tags and keeps a regional-flag tag sequence. Vendor `_meta` is kept. A prefix is reserved when a `modelcontextprotocol` or `mcp` label is followed by another label, and when the second label is one of those two names. Hermes passes a string `command` to a stdio child. This proposal does not.

The live seam is `cosmos/cosmos_mcp_client.py`. It already speaks newline-delimited JSON-RPC, refuses a string argv, and denies `browser_run_code_unsafe` before `tools/call`. This proposal does not import that module and does not spawn.

## Operations

`initialize`, `tools_list`, `tools_call`, and `initialized` build JSON-RPC 2.0 objects for one granted server id. `tools_call` builds a frame. It does not enable a tool. `encode_frame` and `parse_frame` turn those objects into one NDJSON line and back. `filter_tools(names, allow, deny)` keeps names that match `allow` and do not match `deny`. An empty or missing allow list raises `EMPTY_ALLOW`. A name on both lists is dropped: deny wins. That is stricter than the Hermes note that include wins. `guarded_tools_call` applies the same filter and always unions `POLICY_DENY` (`browser_run_code_unsafe`).

`admit_tools` stores the injected exact allowlist for one granted server. An empty allow enables nothing. `resolve_tool` returns a name only when that grant lists it. A third name raises `TOOL_DENIED`. `rebuild` from those records, or from `snapshot` pairs, reproduces the same grants. Duplicate server ids and duplicate tool ids refuse.

`registered_name` prefixes a tool. `utility_tools` and `present_tool` describe the model-facing surface. `select_views` keeps descriptions that fit a budget and skips one that does not, without dropping a later view that fits. `sampling_request` returns a frozen `SamplingRequest` whose `code` is `SAMPLING_CONFIRM` and whose `approved` field is false. A requested token or timeout above the policy cap is stored as the request and applied at the cap. `elicitation_request` returns an unapproved form record and refuses URL mode. `unspawned_argv` returns a `list[str]` copy. A `str` command raises `SHELL_STRING`. `stdio_spec` jails `cwd` through `PathJail` and sets `spawned` false. `http_target` stores a URL and a credential id and sets `connected` false. `connect` raises `NO_CONNECT` and opens nothing. `load_from_path` raises `DISK_IMPORT` and does not open the path. `discovery_limit` clamps concurrency to 4. A requested 0 does not mean unlimited. `confirming_retry` allows one retry, and only for `TIMEOUT`. `note_id` refuses a repeated request id. `accept_window` refuses a stamp outside the applied window and does not raise that window past `WINDOW_CAP`. `sanitize_text` and `visible_meta` clean tool text.

## Authority

A server id is authority only when it sits in the caller grant set. Tool names become enabled only from the injected allowlist on a `ToolGrant`. Sampling and elicitation stay unapproved here. A person confirms them later. Credential material is an id, not a key, a bearer token, or an `api_key=` assignment. The proposal writes no ledger row, starts no process, opens no connection, and loads no code from disk. The returned records are descriptors.

## Landing

CCr can call these builders from `cosmos_mcp_client.py` and keep `StdioTransport` as the only spawner. Wire `SamplingRequest` and `ElicitationRequest` into `cosmos_approval` before any model call or user prompt is treated as granted. Register a tool only after `resolve_tool` accepts it. Do not register a tool `filter_tools` or `POLICY_DENY` dropped. Do not accept a string `command`. Do not raise `TOKEN_CAP`, `TIMEOUT_CAP`, `DISCOVERY_CAP`, `WINDOW_CAP`, or `DESC_BUDGET` from caller input. Do not load a server module from a path and do not open the HTTP descriptor here.

This module still refuses to spawn a process, open a connection, load code from a path, approve sampling, approve elicitation, accept URL elicitation, accept a string command, or enable `browser_run_code_unsafe`. An empty allow enables nothing. A tool name that is not on the injected grant is not enabled.

Hot path: `filter_tools` makes one pass. Exact allow and deny names sit in sets, and only glob patterns are scanned. Deny wins. A repeated name is skipped. `resolve_tool` is one set lookup on the injected grant. `select_views` makes one pass, skips a description that does not fit the remaining budget, and keeps a later view that does.
