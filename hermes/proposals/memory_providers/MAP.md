# Memory providers

Hermes keeps built-in memory active and adds at most one external memory provider. The external names are honcho, openviking, mem0, holographic, retaindb, byterover, supermemory, and hindsight. Built-in memory stays on beside that provider. Hermes injects provider context, prefetches memories before a turn, syncs the turn afterward, and mirrors a built-in write onto the configured external. This proposal records that choice in a projection. It does not call the provider.

The live seam is a projection. `cosmos_recall.py` remains session recall and is not this module. A missing index is `UNMEASURED`. A lookup of a provider that is not among the measured bindings is `UNMEASURED`, not an empty result. Two configured providers and a lookup of a third name refuse. `probe_index` resolves a path through `PathJail` and refuses a missing file with `UNMEASURED` without creating it. An on-disk file is not the authority.

`assemble` builds a generation-zero snapshot from bindings and notes and chains each fact to the previous tip. `rebuild` is the only way a fresh board becomes measured. A failed rebuild leaves the previous snapshot in place. `export` returns that snapshot, and rebuilding the export reproduces status, lookups, and the generation fence. `configure` selects one external provider on a measured board and drops the previous external. `remember` stores a fact. A built-in remember also stores a satellite mirror when an external provider is measured. `forget` deletes one built-in fact and relinks the chain. `search` scans one provider. `prefetch` scans every measured provider. `sync_turn` records the turn on each measured provider and returns a descriptor whose `executed` flag is false. `lookup` returns one provider's capped rows. `holds_credential` compares credential ids. `status` lists the measured providers.

Authority lives in the projection. A human chooses the bindings that `rebuild` measures. Credential material stays an id. A mutation must present the current generation as `seen`. A stale or replayed fence refuses and leaves the snapshot unchanged. Satellite deletion and provider I/O stay outside this module.

Refusal codes: `UNMEASURED`, `UNKNOWN_PROVIDER`, `SECRET`, `LOCAL_ONLY`, `SATELLITE`, `ABSENT`, `EMPTY`, `DUPLICATE`, `STALE`, `BROKEN_CHAIN`, `CONFLICT`, `MISSING_BUILTIN`, `BAD_SNAPSHOT`, `NOT_ROWS`, `FOREIGN_INDEX`, `NO_GRANT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, `OUT_OF_RANGE`, plus the path-jail codes from `probe_index`.

CCr would land this module as a projection beside recall. The harness would rebuild from records it already holds and would hand a `sync_turn` descriptor for the configured satellite to the existing credentialed rail. The module stays free of sockets. A missing index stays `UNMEASURED`.

## Ship

- operations: `BUDGET`, `GENESIS`, `INPUT_CAP`, `POLICY_CAP`, `PROVIDERS`, `SCHEMA`, `TEXT_CAP`, `Binding`, `Fact`, `Hit`, `Lookup`, `MemoryProviders`, `Note`, `Prefetch`, `ProviderStatus`, `SearchResult`, `Snapshot`, `SyncPlan`, `assemble`, `probe_index`. `MemoryProviders` methods are `rebuild`, `export`, `status`, `lookup`, `search`, `prefetch`, `remember`, `forget`, `configure`, `sync_turn`, and `holds_credential`. Properties are `cap`, `external`, and `generation`.
- refusal codes: `UNMEASURED`, `UNKNOWN_PROVIDER`, `SECRET`, `LOCAL_ONLY`, `SATELLITE`, `ABSENT`, `EMPTY`, `DUPLICATE`, `STALE`, `BROKEN_CHAIN`, `CONFLICT`, `MISSING_BUILTIN`, `BAD_SNAPSHOT`, `NOT_ROWS`, `FOREIGN_INDEX`, `NO_GRANT`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, `OUT_OF_RANGE`, plus path-jail codes `BAD_PATH`, `FILE_URL`, `ENCODED_DOTDOT`, `DOTDOT`, `UNC`, `DRIVE_ROOT`, `DRIVE_RELATIVE`, `ALT_STREAM`, `TRAILING_DOT`, `RELATIVE_GRANT`, `RELATIVE_PATH`, and `OUTSIDE_GRANT`.
- what this module still refuses to execute: calling a memory provider, opening a socket, deleting a satellite fact, writing `MEMORY.md` or `USER.md`, creating an index file on read, and treating an on-disk file as the projection. `sync_turn` and `prefetch` are descriptors over the measured snapshot. `executed` stays false.
- hot-path shape: one pass over measured facts in chain order. Membership of provider names is a set. Skip a fact that does not fit the remaining character budget. Stop once the applied count is full. A requested limit above 8 is ignored and the result records the policy cap.
