# Computer use

Hermes drives a desktop through the `computer_use` toolset: move, click, type, key, and screenshot, normally in the background so the real pointer and focus stay put. Destructive desktop actions sit behind the approval gate. Session modes are `standard` (human approval) and `bounded` (a reviewed app allowlist). `off`, `yolo`, and unrestricted dispatch are not modes. A missing or empty allowlist enables nothing. Screenshot retention is 20 captures. Typed shell payloads and lock, logout, empty-trash, and force-delete chords are refused, including when extra keys are held with them. `control+alt+delete` is a lock chord. Stale capture state may be confirmed once. Browser pages stay on the browser toolset. This proposal does not spawn a driver, read pixels, send telemetry, or post input.

The live confirm seam is `cosmos/cosmos_approval.py`. No COSMOS module owns a pointer, keyboard, or display. The descriptor is a new seam. This package does not import the approval module.

`move`, `click`, `type_text` (kind `type`), `key`, and `screenshot` return a frozen `Action`. A `screen` label names the display and is not a device handle. Coordinates are integers on the closed interval 0..10000. `classify(action)` returns `CONFIRM` for every legal action, including click and move. `run(action)` raises `NOT_RUN` and does not inspect the action. `retry` rebuilds the same descriptor once when the failure is `STALE_CAPTURE`. `rebuild` from an action or its field dict returns the same public action. A higher `captures` or `text_chars` request at or below 1000000 is ignored and the policy cap (20 captures, 4000 characters) is recorded. A request above 1000000 or below 1 is refused. A lower request at or above 1 is kept. Bounded mode stores the reviewed app names. A manifest path, when present, is contained with `PathJail` and is not read. Kind, mode, surface, and allowlist tokens are exact. Key names accept case and the closed alias set.

Authority for a later dispatch is a human grant on the approval ledger. This module holds no device handle, no nonce, and no credential material. `standard` still classifies as `CONFIRM`. An allowlist entry is not an approval. A background label does not cover the foreground.

Refusal codes: `BAD_ACTION`, `BAD_ALLOWLIST`, `BAD_CAP`, `BAD_COORD`, `BAD_JAIL`, `BAD_KEY`, `BAD_MODE`, `BAD_PATH`, `BAD_SCHEMA`, `BAD_SCREEN`, `BAD_SESSION`, `BAD_SURFACE`, `BAD_TEXT`, `BLOCKED_KEY`, `BLOCKED_TYPE`, `EMPTY_ALLOWLIST`, `NOT_LISTED`, `NOT_RUN`, `NO_RETRY`, `RETRY_CAP`, `SECRET_SHAPE`, `UNCLASSIFIED`. Bounds add `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, and `OUT_OF_RANGE`. A jailed manifest also refuses with `NO_GRANT`, `RELATIVE_GRANT`, `RELATIVE_PATH`, `OUTSIDE_GRANT`, `DOTDOT`, `ENCODED_DOTDOT`, `FILE_URL`, `UNC`, `DRIVE_ROOT`, `DRIVE_RELATIVE`, `ALT_STREAM`, and `TRAILING_DOT`. There is no `off` mode and no `yolo` mode.

## Ship

- operations: `ACTIONS`, `CONFIRM`, `COORD_MAX`, `COORD_MIN`, `MODES`, `POLICY_CAPTURES`, `POLICY_TEXT`, `REQUEST_CEILING`, `SCHEMA`, `STALE_CAPTURE`, `Action`, `Caps`, `classify`, `click`, `key`, `move`, `rebuild`, `retry`, `run`, `screenshot`, `type_text`
- refusal codes: `ALT_STREAM`, `BAD_ACTION`, `BAD_ALLOWLIST`, `BAD_CAP`, `BAD_COORD`, `BAD_JAIL`, `BAD_KEY`, `BAD_MODE`, `BAD_PATH`, `BAD_SCHEMA`, `BAD_SCREEN`, `BAD_SESSION`, `BAD_SURFACE`, `BAD_TEXT`, `BLOCKED_KEY`, `BLOCKED_TYPE`, `DOTDOT`, `DRIVE_RELATIVE`, `DRIVE_ROOT`, `EMPTY_ALLOWLIST`, `ENCODED_DOTDOT`, `FILE_URL`, `NOT_INT`, `NOT_LISTED`, `NOT_RUN`, `NOT_TEXT`, `NO_GRANT`, `NO_RETRY`, `NULL_BYTE`, `OUT_OF_RANGE`, `OUTSIDE_GRANT`, `OVERSIZE`, `RELATIVE_GRANT`, `RELATIVE_PATH`, `RETRY_CAP`, `SECRET_SHAPE`, `TRAILING_DOT`, `UNC`, `UNCLASSIFIED`
- what this module still refuses to execute: pointer motion, clicks, keystrokes, screenshots, a driver spawn, telemetry, a pixel read, a subprocess, and browser-page control. `run` raises `NOT_RUN` and does not inspect the action. `off` and `yolo` are not modes. An allowlist entry is not an approval. A blocked chord stays blocked when extra keys are held.
- hot-path shape: one pass over the fields; allowlist, app, key, and blocked-chord membership use sets; capture and text caps clamp once to policy; a request above the ceiling is refused before the clamp.

CCr would land this later by submitting each `Action` to `cosmos_approval` as `CONFIRM`, binding a consumed grant to that descriptor's digest, and leaving device dispatch outside this package. `run` stays a refusal until that grant exists. The capture cap stays 20 and the coordinate ceiling stays 10000.
