# platforms

Hermes messaging is one gateway in front of many chat adapters. This proposal allowlists twenty ids: `cli`, `telegram`, `discord`, `slack`, `whatsapp`, `signal`, `matrix`, `mattermost`, `email`, `sms`, `dingtalk`, `feishu`, `wecom`, `weixin`, `qq`, `yuanbao`, `bluebubbles`, `homeassistant`, `teams`, and `google_chat`. Any other name refuses. An adapter stays disabled until `enable` is given a credential id. A saved id is not a live connection. Inbound work is parse. Outbound work is a text descriptor with a length cap. `send` returns that descriptor and does not transmit. A messaging platform cannot take a terminal tool. `terminal`, `process`, `shell`, and every stock preset that bundles a terminal, including `hermes-telegram`, raise `MESSAGING_TERMINAL`. `cli` may name those tools only as a note whose `runs` flag is false. Safe notes (`clarify`, `memory`, `todo`, `vision`, `web`) also do not run. `all` and `*` do not expand. Pairing, user allowlists, markdown dialects, delivery, and reconnect stay outside this module.

The live seam is disabled until a secret id. This is a new messaging seam. `cosmos/cosmos_platform.py` owns process encoding, argv, and tree-kill. It does not own chat adapters, and it does not turn a telegram preset into a terminal grant.

`Platforms()` starts with every id disabled. `enable(id, secret_id)` returns a new value with that id enabled and does not change the previous value. `secret_id` is a credential id, not key material. An empty id is `NO_SECRET`. Key-shaped text and raw bot tokens (`123456789:AAH…`, `xoxb-…`, `Bot <token>`, `bot_token=`) are `SECRET`. `parse(id, text)` returns an `Inbound` only after enable. A disabled id is `DISABLED` before the text or the tool name is judged. Inbound text is bounded by the shared text limit. `format_out` and `send` return an `Outbound` whose text is at most 4000 characters. A requested cap above 4000 and at most `REQUEST_CAP` is ignored as the applied cap, and the stored applied cap is 4000. The asked value is recorded on `requested`. A smaller positive cap is applied and recorded. A non-int, a bool, a non-positive int, or a request above `REQUEST_CAP` is `BAD_CAP`. The cut has no suffix. The tail is not stored. `truncated` is true when the cut happens. A prefix that is only spaces is still the descriptor, because the original message was not blank. `request_tool` checks enablement before the tool name. `rebuild` from the enabled rows returns an equal desk. No method opens a socket.

Authority lives with the human who chooses the credential id. This module does not check a vault, write a file, start a process, or send the formatted text. The caller holds the enabled set. A tool note is not permission to run.

## Ship

- operations: `PLATFORM_IDS`, `REQUEST_CAP`, `SAFE_TOOLS`, `SCHEMA`, `TERMINAL_TOOLS`, `TEXT_CAP`, `Enabled`, `Inbound`, `Outbound`, `Platforms`, `ToolNote`, `rebuild`, plus methods `enable`, `parse`, `format_out`, `send`, `request_tool`
- refusal codes: `UNKNOWN_PLATFORM`, `NO_SECRET`, `SECRET`, `DISABLED`, `EMPTY`, `BAD_ID`, `BAD_NAME`, `BAD_CAP`, `BAD_RECORD`, `DUPLICATE`, `MESSAGING_TERMINAL`, `UNKNOWN_TOOL`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`
- what this module still refuses to execute: a socket send, a process, a terminal tool on any messaging platform (including the `hermes-telegram` preset and the rest of `TERMINAL_TOOLS`), a cli terminal note (`runs` is false), a safe-tool note, a raw bot token, and any platform that has no credential id. `all` and `*` do not expand.
- hot-path shape: one set lookup for the platform id, one dict lookup for enablement, one secret scan, then either a prefix cut under the policy cap or a set test on the tool name. A terminal-class name on a messaging platform refuses and grants nothing.

CCr would land this as a new messaging seam beside the gateway, not inside `cosmos_platform.py`. The gateway calls `enable` with a vault id, `parse` on an inbound event, and `send` before any network delivery. `request_tool` stays in front of tool schema construction so a telegram preset cannot turn the terminal on. The landing adds no socket, no token field, and no adapter client. Network delivery waits for a separate authorized rail.
