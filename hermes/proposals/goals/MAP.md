# Goals

Hermes `/goal` keeps one standing objective in the current session. After a turn, a judge is asked whether the objective is done, still open, or unachievable. A continue result feeds a continuation prompt back into that same session. The loop stops when the goal is done, when it is paused or cleared, or when the turn budget is spent. The default budget is 20 turns. Resume starts another measured chunk. Setting a goal does not create a kanban card. A completion contract, extra subgoals, a shell quality gate, or a wait on a background process can narrow when completion is allowed. Those checks belong to a later runner. This package does not call a model, start a process, or treat the success condition as code.

The live seam is new: named predicates. COSMOS has no goals module yet. This proposal does not import a live module and does not replace one.

`create(text, predicate_id)` stores one open goal. `predicate_id` must match `^[a-z0-9_]{1,32}$`. An id that contains `(` raises `BAD_PREDICATE`. The id is stored as text and is never compiled or called. Goal text, a mark reason, a continuation note, or an evidence note that matches `secret_shape`, or that contains `disable approval`, raises `GUARD_ESCAPE`. An empty goal, including a goal that is only zero-width marks, raises `EMPTY_GOAL`. `status()` returns `open` until a terminal mark. `mark("done")` is met only when `evidence` names that same predicate. A missing name, or a different name, raises `UNMET` and the goal stays open. A reason string is not evidence. `prove` builds that named evidence. `mark("refused")` does not accept evidence (`BAD_EVIDENCE`). Any other mark raises `BAD_STATUS`. A second terminal mark raises `NOT_OPEN`. `advance` records one continuation and returns a `Continuation` descriptor. It does not start a turn and it does not meet the goal. When `turns_used` reaches the effective turn cap, `advance` raises `BUDGET` and the status stays `open`. `gap` confirms the named failure `JUDGE_GAP` once. The next gap raises `RETRY_CAP`. Any other failure class raises `UNCLASSIFIED`. A judge gap is not evidence and is not a fail-open continue. An explicit allowlist must contain the predicate id. An empty allowlist raises `EMPTY_ALLOW`. A repeated id raises `DUPLICATE`. A missing allowlist does not invent names; the id still has to match the name shape. `emit` writes a `Record`. `rebuild` of that record returns an equal `Goal`. A bad record raises `BAD_RECORD`. A digest that does not match raises `CHAIN`.

`TURN_CAP` is 20. A `max_turns` above 20 is stored on `Policy.asked_turns` and the enforced `turn_cap` stays 20. A lower positive ask is the enforced cap. A hand-built policy that raises the cap raises `BAD_POLICY`. A done goal whose stored evidence does not name the predicate raises `UNMET`.

Authority is the session ledger. This module returns frozen records a later writer would append. A human marks the goal refused, or marks it done only by supplying the named evidence. The caller passes `now`. The package reads no clock, opens no socket, and writes no file. `repr` omits goal text, reasons, and notes.

Refusal codes: `BAD_EVIDENCE`, `BAD_POLICY`, `BAD_PREDICATE`, `BAD_RECORD`, `BAD_SCHEMA`, `BAD_STATUS`, `BUDGET`, `CHAIN`, `CLOCK`, `DUPLICATE`, `EMPTY_ALLOW`, `EMPTY_GOAL`, `GUARD_ESCAPE`, `NOT_INT`, `NOT_LIST`, `NOT_LISTED`, `NOT_OPEN`, `NOT_TEXT`, `NULL_BYTE`, `OUT_OF_RANGE`, `OVERSIZE`, `RETRY_CAP`, `UNCLASSIFIED`, `UNMET`.

CCr would land this later by appending `Goal` and `Continuation` to the session ledger under one goal key, and by letting the harness consume the descriptor. The predicate id stays a name in that ledger. Done still requires named evidence from outside this module. The judge remains an external verdict token, with one confirming retry for `JUDGE_GAP` and no fail-open continue. The turn cap stays 20 unless the stored ask is lower. Shell gates and process waits stay outside this package.

## Ship

- operations: `SCHEMA`, `TURN_CAP`, `TEXT_CAP`, `ALLOW_CAP`, `RETRY_FAILURE`, `Policy`, `Continuation`, `Evidence`, `Goal`, `Record`, `create`, `prove`, `emit`, `rebuild`. `Goal` methods: `status`, `mark`, `advance`, `gap`.
- refusal codes: `BAD_EVIDENCE`, `BAD_POLICY`, `BAD_PREDICATE`, `BAD_RECORD`, `BAD_SCHEMA`, `BAD_STATUS`, `BUDGET`, `CHAIN`, `CLOCK`, `DUPLICATE`, `EMPTY_ALLOW`, `EMPTY_GOAL`, `GUARD_ESCAPE`, `NOT_INT`, `NOT_LIST`, `NOT_LISTED`, `NOT_OPEN`, `NOT_TEXT`, `NULL_BYTE`, `OUT_OF_RANGE`, `OVERSIZE`, `RETRY_CAP`, `UNCLASSIFIED`, `UNMET`
- what this module still refuses to execute: a judge call, a shell gate, a process wait, a continuation prompt, and any use of the predicate as code. `Continuation` is a descriptor. Missing evidence does not become done. There is no fail-open continue.
- hot-path shape: one pass over the allow list into a set; one const_eq of the evidence name to the predicate id; the secret scan runs again only when zero-width marks were removed
