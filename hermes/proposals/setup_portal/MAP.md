# setup_portal

`hermes setup --portal` is the one-shot Nous Portal setup. The operator logs in through the portal, the provider becomes Nous, and the Tool Gateway turns on for web search, image generation, text-to-speech, and browser automation. Hermes keeps a refresh token in the profile. This proposal plans that choice and hashes the plan. It does not log in, open a browser, bind a port, or write a token.

The live seam is new. No COSMOS module owns a portal setup plan. Credential ids stay on the existing credential store. This proposal does not import that store and does not accept raw key material.

`plan(provider, tools, cred_ids)` returns a frozen `Plan`. `provider` matches `^[a-z0-9](?:[a-z0-9-]*[a-z0-9])?$` inside the applied name cap (`NAME_CAP` 32). `tools` is a non-empty list or tuple drawn from `web`, `image`, `tts`, and `browser`, at most the applied `TOOL_CAP` (4). `cred_ids` is a non-empty list or tuple of credential ids, at most the applied `CRED_CAP` (8), each at most `CRED_LEN` (64). `cred-model` and `cred-voice` are ids, not keys. Stored tools and credential ids are sorted, so input order does not change the plan. `plan_hash` is sha256 of canonical JSON (`sort_keys`, compact separators) of `provider`, `schema`, `tools`, and `cred_ids`. A requested cap above its policy ceiling is ignored. `Plan.clamped` records that. Applied fields keep the policy ceilings, and the requested values stay on the plan. A lower positive cap is the applied cap. The hash ignores caps.

`persist(mapping)` walks nested strings once. It raises `SECRET` when `secret_shape` matches a key or a string value, and otherwise returns the same mapping. It writes no file. `save(mapping)` runs that gate and then raises `NO_DISK`. `open_port` accepts only the loopback name, then raises `NO_SOCKET`. `confirm` authorizes at most one retry, and only for `CALLBACK_UNREACHABLE`. `snapshot` emits the public record. `rebuild` reproduces the plan. A mismatched hash is `CHAIN`. `listens` is always false. `same` compares plan hashes with `const_eq`. The module schema is `cosmos-hermes-setup_portal/1`.

Authority is human. The caller names the provider, the tool subset, and the credential ids. The plan is a descriptor for a later clock. Persist is the gate in front of any config write. This module does not spend, append a ledger, or dial a portal.

## Ship

- operations: `SCHEMA`, `NAME_CAP`, `TOOL_CAP`, `CRED_CAP`, `CRED_LEN`, `TOOLS`, `LOOPBACK`, `RETRY_CLASS`, `MAX_CONFIRMING_RETRIES`, `Plan`, `Confirm`, `plan`, `persist`, `save`, `open_port`, `snapshot`, `rebuild`, `same`, `confirm`. `Plan` fields are `provider`, `tools`, `cred_ids`, `plan_hash`, `name_cap`, `tool_cap`, `cred_cap`, `requested_name_cap`, `requested_tool_cap`, `requested_cred_cap`, `clamped`, `listens`, and `schema`.
- refusal codes: `BAD_TOOL`, `BAD_PROVIDER`, `BAD_CRED`, `BAD_HOST`, `BAD_KEY`, `BAD_LIMIT`, `BAD_MAPPING`, `BAD_PLAN`, `BAD_RECORD`, `BAD_VALUE`, `CHAIN`, `DUPLICATE`, `EMPTY_ALLOW`, `MISSING_ID`, `NO_DISK`, `NO_SOCKET`, `NOT_BOOL`, `NOT_INT`, `NOT_TEXT`, `NULL_BYTE`, `OUT_OF_RANGE`, `OVERSIZE`, `RETRY`, `SECRET`, `TOO_DEEP`, `TOO_MANY`, `UNCLASSIFIED`.
- what this module still refuses to execute: opening a port, writing a file, storing raw `sk-`, `Bearer`, or `api_key=` material, logging into the portal, launching a browser, raising a cap, a second confirming retry, and any failure class other than `CALLBACK_UNREACHABLE`. `listens` cannot be set true. A credential id is not resolved against a store.
- hot-path shape: one pass over tools and one pass over credential ids, with set membership for the allowlist and for duplicates; one sha256 of the canonical body; one pass over a persist mapping that stops at the width cap. Over-cap collections refuse. Later ids are not dropped to keep an earlier bad id.

CCr would later call `plan` when an operator chooses portal setup and store `plan_hash` as the plan id. The refresh token stays inside the credential-id store, never inside this mapping. `save` runs before any config write, so a secret-shaped string never reaches disk and a clean mapping is still not written here. The tool subset stays inside `web`, `image`, `tts`, and `browser`. No HTTP client and no listening socket are added.
