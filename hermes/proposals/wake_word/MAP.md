# wake_word

Hermes arms a local listener for the spoken phrase "hey hermes" on the CLI, the TUI, or the desktop GUI. A hit pauses the listener and asks voice mode for a fresh session. Detection stays on the device. The gate stays dark until a human arms it. Messaging surfaces stay outside the surface allowlist. The engine label is `auto`, `openwakeword`, `sherpa`, or `porcupine`. The label `cloud` is a cloud recognizer and is refused. A repeated surface id is refused. `auto` selects from a caller-supplied platform label: sherpa on Windows ARM64, Intel macOS, and Linux ARM64; openWakeWord on Windows x64, Apple Silicon, and Linux x64. An explicit engine stays selected on a platform that supports it. A custom openWakeWord phrase carries a `.tflite` path inside a path grant. Porcupine carries a credential id. The bundled openWakeWord detector name is `hey_hermes`. Porcupine's detector name stays `jarvis` until a `.ppn` path is granted. Sherpa detects the typed phrase.

The live seam is on-device only. `cosmos/cosmos_voice.py` owns the utterance once a session exists. Wake arming, the on-device flag, and the cooldown are this proposal. A cloud recognizer never arms. `on_device` is required.

Operations are `WakeWord.enable`, `WakeWord.disable`, `WakeWord.hear`, `WakeWord.set_cooldown`, and `WakeWord.status`. `enable(True)` returns a frozen `Arm` with `opens_device` false. `enable(False)` raises `CLOUD_WAKE` and leaves the previous arming unchanged. `hear(score, now)` below 0.5 returns `MISS`. A score of 0.5 or higher returns a frozen `SessionRequest` whose `kind` is `session-request`. The record names the phrase, the engine, the surface, the capture mode, and the caller-supplied time. `opens_device` stays false. A later `hear` inside the effective cooldown raises `COOLDOWN`. A cooldown request below 2 seconds is stored on `requested` and `effective` stays 2. A request above 120 seconds is stored on `requested` and `effective` stays 120.

Authority to arm sits with the human. The session request is a descriptor for a later voice service. Ledger writes, projection updates, and attempt-workspace writes stay with that later service. The clock value is the `now` argument.

Refusal codes: `CLOUD_WAKE`, `COOLDOWN`, `NOT_ARMED`, `REWOUND`, `BAD_SCORE`, `NOT_INT`, `OUT_OF_RANGE`, `NOT_BOOL`, `EMPTY_PHRASE`, `BAD_PHRASE`, `SECRET_SHAPE`, `OVERSIZE`, `NULL_BYTE`, `NOT_TEXT`, `BAD_SURFACE`, `NOT_LOCAL`, `EMPTY_ALLOW`, `BAD_ALLOW`, `DUPLICATE`, `SURFACE_DENIED`, `BAD_CAPTURE`, `BAD_PROVIDER`, `BAD_PLATFORM`, `UNSUPPORTED_ENGINE`, `MISSING_CRED`, `BAD_CRED`, `NEED_MODEL`, `BAD_MODEL`, `NO_GRANT`, `BAD_GRANT`, and the path-jail codes for a model path outside the grant.

CCr lands this beside `cosmos_voice.py`. The human arms the on-device gate. A hit becomes a new voice session through the existing voice loop. Cloud wake stays a `CLOUD_WAKE` refusal. The cooldown floor stays 2 seconds. The microphone stays closed here; the voice service is what later captures the utterance.

- what this module still refuses to execute: opening a microphone, reading PCM, downloading a model, calling a cloud recognizer, arming a messaging surface, installing a package, and writing a ledger or a file. A hit is a session-request descriptor with `opens_device` false.
- hot-path shape: one pass. Bound the clock and the score before the cooldown check. A score under the threshold returns `MISS` and leaves the gate armed for a later sample. Sets hold engines, surfaces, and captures.
