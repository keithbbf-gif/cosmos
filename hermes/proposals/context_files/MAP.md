# context_files

Hermes loads one project context file, first match wins: `.hermes.md`, then `HERMES.md`, then `AGENTS.override.md`, then `AGENTS.md`, then `CLAUDE.md`, then `.cursorrules`. `SOUL.md` is a separate identity note from the Hermes home. An empty soul adds nothing. Inside a git checkout Hermes also merges `AGENTS.md` from the repo root down to the working directory and drops identical copies. Outside git it does not walk parents. Subdirectory files show up later, once per directory, on the tool result, with a fixed 32,000-character preview. A prompt-injection hit blocks a project file. A hit on the operator's own soul is logged and still loaded. Startup files over the configured cap are head-and-tail truncated.

The live seam is `cosmos/cosmos_spawn.py`. That module owns spawn context: role, wrapper, skills, tools, and params. `require_context_list` already refuses a concatenated context string. Session handoff stays in `cosmos/cosmos_context.py`. This proposal does not open wrapper paths and does not start a second spawn.

`load` reads absolute paths only after `cosmos_hermes.PathJail.contain`. `assemble` packs `(name, text)` pairs the caller already holds. Both keep one project winner. `COSMOS.md` is an extra local note and does not compete with that winner. `.mdc` rule names load only when no project winner was supplied, in sorted name order. `SOUL.md` is appended as plain text, without a section header. Empty text adds nothing and still claims its name. A second copy of a claimed name raises `DUPLICATE`. A file longer than the file cap, or a read longer than `BYTE_CAP`, raises `OVERSIZE`. The selector then walks the chosen notes once: a note that does not fit the remaining total is recorded as `dropped` and later notes that fit are kept. A caller who asks for a higher cap is ignored. The pack records the policy caps. Secret-shaped names and file text raise `SECRET_SHAPE` and are not stored. A guard hit is not loaded, including on `SOUL.md`, because this module cannot prove the file is the operator's home copy. The same inputs return the same pack. `rebuild` from that pack returns an equal pack. There is no retry class. The module does not write, walk parents, or follow a git chain.

The human authors the files. Inclusion authority is this policy. Spawn authority stays in `cosmos_spawn.apply`. The pack is not a ledger entry, not a tool grant, and not an approval.

CCr later chooses the context paths inside the attempt workspace, passes them through the existing path jail into `load`, and places `prompt` on the spawn wrapper. The caps stay 32,000 characters per file, 128,000 bytes on the read, and 64,000 characters across the kept texts. Git walks and progressive subdirectory hints stay in the workspace reader.

Recorded on `skipped`: `ILLEGAL_NAME`, `EMPTY`, `GUARD_ESCAPE`, `SUPERSEDED`. Recorded on `dropped`: `OVERSIZE` when the remaining total cannot hold the note.
- what this module still refuses to execute: no spawn, no parent walk, no git merge, no progressive tool-result injection, no head-and-tail truncation, no write, no network, and no load of a guard-hit soul
- hot-path shape: one claim pass over the pairs, then one priority pass that skips a body which does not fit the remaining total and keeps a later body that fits
