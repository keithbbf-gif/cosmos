# acp

Hermes can run as an ACP server so an editor renders chat, tool activity, file diffs, terminal commands, and approval prompts. Hosts include VS Code, Zed, JetBrains, and Buzz. The editor owns the transport. Hermes keeps its identity, tools, and credentials. A session remembers an id, a working directory, a model label, history, and a cancel flag. Dangerous terminal lines return allow once, allow for session, allow always, or deny. Timeout and error deny. This proposal does not start an editor, does not open stdio, and does not run a command.

The live seam is editor messages, and it is new. `cosmos/cosmos_approval.py` already owns human approval. No COSMOS module owns an ACP session or an editor process.

`open_desk` binds a `PathJail` and a method allowlist. The policy allowlist is `initialize`, `session/cancel`, `session/close`, `session/list`, `session/new`, `session/prompt`, and `session/resume`. A caller-supplied list may only narrow that set. An empty list is `EMPTY_ALLOW`. A name outside the policy set is `BAD_METHOD`. `answer` parses one JSON-RPC 2.0 editor message and returns an `Exchange`. The reply `sent` flag stays false. `initialize` then `session/new` round-trips: the desk stores the client name and one session whose cwd resolved inside the jail, and the reply carries `protocolVersion` 2 and a `sessionId`. A method that is not on the desk allowlist raises `UNKNOWN_METHOD`. `session/prompt` inserts text blocks and returns a `messageId` plus an unsent `user_message` note. It does not call a model. `session/cancel` is a notification and marks the session cancelled. `session/list` skips closed sessions and keeps later open ones. Non-empty `mcpServers` raises `MCP_REFUSED` and no server is started. `message` still classifies `prompt`, `tool`, `diff`, and `terminal`. A terminal record's code is `NEED_APPROVAL`. `decide` records an approval choice with `runs` false and `persisted` false. Timeout and error record as deny. `rebuild` from the public records returns the same desk.

Authority for a display record is the projection an editor would render. Authority for a terminal line and an approval choice is the human. Authority for a path is the attempt-workspace grant. The desk is not a process and not a ledger.

The text cap is 32000 characters. A requested cap above that is ignored and the policy cap is recorded. A lower positive cap is honored. There is no retry class.

Refusal codes: `ALREADY`, `BAD_CHOICE`, `BAD_CODE`, `BAD_CONTENT`, `BAD_ID`, `BAD_JAIL`, `BAD_KIND`, `BAD_LIMIT`, `BAD_MESSAGE`, `BAD_METHOD`, `BAD_NOTIFY`, `BAD_PARAMS`, `BAD_PATH`, `BAD_SCHEMA`, `BAD_TEXT`, `BAD_VERSION`, `CLOSED`, `DUPLICATE`, `EMPTY`, `EMPTY_ALLOW`, `MCP_REFUSED`, `MISMATCH`, `NOT_INT`, `NOT_READY`, `NOT_RUN`, `NOT_SENT`, `NOT_TEXT`, `NO_GRANT`, `NULL_BYTE`, `OUT_OF_RANGE`, `OVERSIZE`, `PERSIST`, `SECRET`, `STALE`, `TOO_DEEP`, `TOO_MANY`, `UNKNOWN_METHOD`, `UNKNOWN_SESSION`, `UNSUPPORTED`. A path `PathJail` rejects also raises that jail code, including `ALT_STREAM`, `DOTDOT`, `DRIVE_RELATIVE`, `DRIVE_ROOT`, `ENCODED_DOTDOT`, `FILE_URL`, `OUTSIDE_GRANT`, `RELATIVE_GRANT`, `RELATIVE_PATH`, `TRAILING_DOT`, and `UNC`.

CCr would later hand `Exchange.reply.body` to an ACP host channel and hand a `TerminalRecord` plus an `Approval` to `cosmos_approval.py`. The landing still does not spawn an editor. A terminal line stays unrun until a human decision arrives from outside this module. `allow_always` stays unpersisted here.

## Ship

- operations: `AGENT_NAME`, `AGENT_TITLE`, `AGENT_VERSION`, `DEPTH_CAP`, `KINDS`, `MESSAGE_CAP`, `METHODS`, `NEED_APPROVAL`, `NODE_CAP`, `PROTOCOL`, `SCHEMA`, `SEEN_CAP`, `SESSION_CAP`, `TEXT_CAP`, `Approval`, `Desk`, `DisplayRecord`, `Exchange`, `Reply`, `Session`, `TerminalRecord`, `Turn`, `answer`, `decide`, `message`, `open_desk`, `rebuild`
- refusal codes: `ALREADY`, `ALT_STREAM`, `BAD_CHOICE`, `BAD_CODE`, `BAD_CONTENT`, `BAD_ID`, `BAD_JAIL`, `BAD_KIND`, `BAD_LIMIT`, `BAD_MESSAGE`, `BAD_METHOD`, `BAD_NOTIFY`, `BAD_PARAMS`, `BAD_PATH`, `BAD_SCHEMA`, `BAD_TEXT`, `BAD_VERSION`, `CLOSED`, `DOTDOT`, `DRIVE_RELATIVE`, `DRIVE_ROOT`, `DUPLICATE`, `EMPTY`, `EMPTY_ALLOW`, `ENCODED_DOTDOT`, `FILE_URL`, `MCP_REFUSED`, `MISMATCH`, `NOT_INT`, `NOT_READY`, `NOT_RUN`, `NOT_SENT`, `NOT_TEXT`, `NO_GRANT`, `NULL_BYTE`, `OUT_OF_RANGE`, `OUTSIDE_GRANT`, `OVERSIZE`, `PERSIST`, `RELATIVE_GRANT`, `RELATIVE_PATH`, `SECRET`, `STALE`, `TOO_DEEP`, `TOO_MANY`, `TRAILING_DOT`, `UNC`, `UNKNOWN_METHOD`, `UNKNOWN_SESSION`, `UNSUPPORTED`
- what this module still refuses to execute: starting an editor, opening stdio, running a terminal line, connecting an MCP server, calling a model, persisting `allow_always`, and writing a ledger or a file. Replies keep `sent` false. Approval records keep `runs` false.
- hot-path shape: one pass over the JSON value, then a set lookup on the method allowlist. A message that does not fit is refused. `session/list` skips closed sessions and keeps later open ones.
