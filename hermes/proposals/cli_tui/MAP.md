# cli_tui

Hermes keeps a terminal composer. A line that starts with `/` is a slash command, and any other line is the prompt. `/help` lists commands, `/tools` lists tools, and `/model` shows or names a model. `/rollback` lists or names a filesystem checkpoint. Approval commands decide dangerous-command prompts, including `manual`, `smart`, and `off`, and `/yolo` skips those prompts. Multiline entry accumulates lines, history keeps the conversation, and Ctrl+C interrupts the running turn. A line that starts with `!` is a host shell.

The live seam is new. No COSMOS module owns the composer. The feature names this seam slash descriptors.

This proposal adds `parse`, `Session.accept`, `Session.append_line`, `Session.flush`, `Session.interrupt`, `Session.transcript`, `rebuild`, and `restore`. `parse("/help")` returns a frozen `Descriptor` and performs no side effect. The command names are `help`, `tools`, `model`, `approval`, `rollback`, and `interrupt`. An unknown slash raises `UNKNOWN_COMMAND`. A line that is not a slash is a frozen `Plain` record and has no command name. `accept` stores that result. `append_line` adds one line to a multiline buffer and does not execute it, even when the line starts with `/`. `flush` joins the buffer into one plain record. `interrupt()` sets a real bool flag. Parsing `/interrupt` does not set the flag and returns a descriptor. `effect` is always `none`. A `!` line is plain text and is not a shell. `/tools` does not invent a tool inventory. `transcript` freezes history, the draft lines, the interrupt flag, and the rollback-miss count. `rebuild` checks those records and returns an equal transcript. `restore` opens a session with that same transcript. The package does not read stdin and does not draw a screen.

Authority to act on a descriptor stays with the human. History and the interrupt flag live in the session object for one attempt. They are not a ledger and they are not a checkpoint store. `/rollback N` names an index for the checkpoints seam. `/model` names a model id for the model allowlist. `/approval` names a manual review for the approval gate.

`HISTORY_CAP` is 50. A 51st accepted line drops the oldest. A caller who asks for a higher history cap or a higher buffer cap keeps the policy cap, and the policy records the asked value. A lower positive cap is honored. `BUFFER_CAP` is 32 lines and `LINE_CAP` is 4000 characters. A joined record is at most `JOIN_CAP`. `ROLLBACK_MISS` is the only confirming retry, and only once, and only on `accept`. The next miss is `RETRY_CAP`. `parse` does not count retries. A successful indexed rollback clears the miss count.

Refusal codes from this module: `UNKNOWN_COMMAND`, `BAD_ARGS`, `BAD_MODE`, `BAD_INDEX`, `BAD_LINE`, `BAD_LIMIT`, `BAD_SCHEMA`, `BAD_EFFECT`, `BAD_FLAG`, `BAD_KIND`, `SECRET`, `BUFFER_FULL`, `EMPTY_BUFFER`, `ROLLBACK_MISS`, `RETRY_CAP`. `bound_text` and `bound_int` still raise `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, and `OUT_OF_RANGE`. `/approval off`, `/approval yolo`, and `/approval smart` are `BAD_MODE`. There is no `off` mode and no `yolo` mode. A bool is not an int: a bool cap is `BAD_LIMIT`, a bool rollback index is `BAD_INDEX`, and a flag that is not `True` or `False` is `BAD_FLAG`.

CCr would land this later as the CLI composer's parser, beside the approval gate and the checkpoint workspace. A later clock reads `Descriptor` and `Interrupt`. It does not grow a shell or a second approver inside this package. The package deletes once that clock owns the six descriptors.

## Ship

- operations: `ASK_MAX`, `BUFFER_CAP`, `COMMANDS`, `EFFECT`, `HISTORY_CAP`, `INDEX_MAX`, `JOIN_CAP`, `LINE_CAP`, `SCHEMA`, `Buffer`, `Descriptor`, `HistoryItem`, `Interrupt`, `Plain`, `Policy`, `Session`, `Transcript`, `parse`, `rebuild`, `restore`. Session methods are `accept`, `append_line`, `flush`, `interrupt`, and `transcript`.
- refusal codes: `UNKNOWN_COMMAND`, `BAD_ARGS`, `BAD_MODE`, `BAD_INDEX`, `BAD_LINE`, `BAD_LIMIT`, `BAD_SCHEMA`, `BAD_EFFECT`, `BAD_FLAG`, `BAD_KIND`, `SECRET`, `BUFFER_FULL`, `EMPTY_BUFFER`, `ROLLBACK_MISS`, `RETRY_CAP`, `NOT_TEXT`, `NULL_BYTE`, `OVERSIZE`, `NOT_INT`, `OUT_OF_RANGE`
- what this module still refuses to execute: a slash command, a host shell, a screen draw, a stdin read, a tool inventory, a checkpoint restore, an approval decision, and a second retry after `ROLLBACK_MISS`
- hot-path shape: one pass over the line for controls, one split, a dict lookup plus one `const_eq` for the command name. Secret text is classified once at the edge. A joined buffer scans the newline-stripped form only when a newline is present, and a line that does not fit is refused without dropping lines already held. History over the cap drops the oldest in one slice.
