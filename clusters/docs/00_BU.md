# BU — Cosmos Clusters

*Read this first. Written 2026-09-30.*

## 30-second version

**Clusters** is a later plugin of COSMOS CODE. Its TUI oversees clusters of agents. A cluster holds agents, agents and other clusters, or only subclusters. Each cluster may have a Manager Agent. The ORC manages multiple clusters. The Pilot manages any or all agents, clusters, managers, and the ORC, directly or indirectly, through HERO PACKS set per Agent and/or per cluster.

The section of record is [`01_CLUSTERS.md`](01_CLUSTERS.md).
