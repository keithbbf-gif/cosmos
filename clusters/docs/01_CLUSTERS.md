## What it is

CLUSTERS is a TUI set up to oversee clusters of agents.

## What a cluster contains

A cluster is composed in any of these ways:

- multiple Agents
- Agents and other Clusters
- only other Clusters (subclusters)

## Who manages

Each cluster has the option of a **Manager Agent**.

The **ORC** can manage multiple clusters.

The **Pilot** can manage any or all agents, clusters, Manager Agents, and the ORC, directly or indirectly.

## HERO PACKS

Management uses HERO PACKS: rules, skills, wrappers, and environments.

A pack is defined per Agent, per cluster, or both.
