# Banquet tables are not this family

A hotel banquet table extends. It
is still not what this series is
about.

Those objects are a kit: plywood
skins, metal aprons, legs that
fold, clips that join one 30-by-96
to the next until the room is a
runway. The plane is a committee.
The mechanism is a truck and a
staff. When the dinner ends the
table leaves the room. That is a
different contract. The room does
not have to live with the closed
state because there is no closed
state, only storage on a cart.

I keep the boundary hard so nobody
imports banquet virtues into a
household and calls it honesty.
Yes, the clips are honest. Yes,
the seating math is blunt. Yes,
you can add length forever. You
also cannot have a Tuesday. You
cannot have a seam that is a
choice. You cannot have a finish
that ages as one object. You
have an event.

Household extensions are the
opposite bet. The object stays.
The guest list changes. The
closed table is furniture. The
open table is the same furniture
under a temporary law. Banquet
gear is temporary law with no
furniture underneath.

There is a gray strip: the
folding "harvest" sold for
apartments, the kind that is a
slim console and then a dinner
for six if you believe the box.
Some of those are gatelegs in
MDF. They belong in this series
as distant cousins. Some are
banquet tables with better
clothes. You can tell which
when you look for a closed life
that you would keep if you never
had guests. If the closed life
is only storage, you bought an
event.

I will steal one thing from the
hotel: the refusal to pretend.
They do not photograph a clip
and call it heirloom. If a
household table needs clips,
name them. If it needs to be
two tables, name that. The
scar is always the same —
calling a kit an object, or
calling an object a kit.
