# Table leaves and extension mechanisms

Draft series. Not a catalog. Not a shop manual. A staged attempt to
say what an extending table *is*, how the idea got here, and why so
many of them still fail at dinner.

The leaf is the board. The mechanism is whatever keeps that board in
the same plane as the rest of the meal — under elbows, under gravy,
in February when the house is dry. People keep talking about the leaf
as if it were the invention. It isn't.

## How to read this

Read in stage order if you want the argument. Skip around if you want
a single object. Every file is a draft with its own opening. If two
pieces say the same sentence, one of them is dead.

| Stage | Job |
|---|---|
| `01-define` | Name the parts. Refuse the marketing words. |
| `02-history` | What actually showed up, and when. |
| `03-mechanisms` | How the motion works when you put a hand on it. |
| `04-design` | What the eye and the sitters get. |
| `05-hardware` | Pins, slides, locks, sag. |
| `06-materials` | Wood that moves, veneer that doesn't, finish that lies. |
| `07-scars` | Failures you can still find under real tables. |
| `08-law` | What a good extension has to do, or it is not one. |

## Voice and fence

sat through. Dates and object numbers when I have them. Guess marked
as guess. Dealer myth marked as myth.

It does not file USPTO. It does not tell you to buy a table.
