# Photo captions

This writer pack does **not** embed photographs. Slots are
listed so an images lane can fill them without inventing
credits. Authority for any later license line lives with the
file that actually lands.

Prefer Keith's library: `D:\BBF\BBF Photos`. If a Commons plate
is used later, it needs a live URL, a license, and a caption
that teaches — not a keyword stack.

## Caption rules

- Credit only what is known. If metadata has no photographer,
  write `photographer unnamed until file metadata is pulled`.
- Never invent a customer standing next to a failed table.
- A diagram, if drawn later, should show rings, grain
  direction, and the arrow of movement — not a decorative
  oak leaf.
- Do not substitute stock interiors of staged living rooms
  for shop proof.

## Rights

Owner clearance required on BBF library files before public
use. Do not commit binary photos in this pack until rights
are written down.
