In April 2020, Zheng, Wittouck, Salvetti, and a long author list published a taxonomic note in the *International Journal of Systematic and Evolutionary Microbiology* (PMID 32293557) that split the old genus *Lactobacillus* into many genera. *Lacticaseibacillus rhamnosus*, *Lactiplantibacillus plantarum*, *Limosilactobacillus reuteri*, *Levilactobacillus brevis* — the new binomials look like typos if you were raised on 1990s labels. *Lactobacillus acidophilus* kept the old genus. The paper is about relatedness, shared characters, and the unworkable size of a genus that had become a junk drawer. It is not about your SKU. It still changed every file that prints a name.

## Why they split it

Genera are meant to be coherent. *Lactobacillus* had swallowed organisms that, by 16S, whole-genome, and ecological habits, did not belong in one box. Microbiologists had complained for years. Zheng et al. proposed twenty-three new genera and reassigned a long list of species. The Judicial process and later list appearances are how names become formal. For our purposes: the scientific literature after 2020 increasingly uses the new combinations. Databases update on their own clocks. Consumer labels update when someone makes them.

ISAPP and several culture houses published explainers: same organism, new address. That sentence is true only if the *strain* is the same. The split did not merge strains. It did not bless every *L. rhamnosus* as GG. It made sloppy species-level copy even sloppier, because the old word *Lactobacillus* on a tub now hides a crowd of genera.

## What must not change, and what must

The strain designation should not change. ATCC 53103 is still ATCC 53103 if that is the isolate. CNCM, DSM, and house numbers still point at a freezer. Binda 2020's deposit criterion did not get easier. If anything, the split is an argument for printing the deposit: it is the only string that survives a rename.

The label's genus+species *should* change if you want the name to match current nomenclature. Some regulators and some retailers still search the old string. That is an operations headache, not a reason to print only "proprietary lactobacillus blend." Dual naming for a transition period — new name, old name in parentheses, strain ID in the same line — is how a careful file behaves. "We kept the old name because customers know it" is how a file becomes incomparable to the trial it cites.

Trials published in 2012 that say *Lactobacillus rhamnosus* GG are still about GG if the strain is GG. You may cite them under the new binomial. You may not cite them for a different *rhamnosus* that never saw a freezer in Gorbach's lab (draft 16).

## Other renames waiting in the same aisle

*Bacillus coagulans* was moved to *Weizmannia coagulans* (Gupta et al., 2020; `[VERIFY]` pagination). Not every house followed. Spore-forming "soil" marketers already play fast with names (draft 18). A rename is a chance to check whether the isolate was ever the type they implied.

*Clostridium difficile* is now *Clostridioides difficile* in much of the clinical literature. That one matters because disease copy must not migrate to a supplement page (draft 10). Get the name right in a research essay; do not get it onto a PDP.

## How this breaks a COA and a PubMed search

A COA that still says *Lactobacillus rhamnosus* without a strain may be describing a real fermentation. It is not describing a unique organism. After 2020, a search for the old name misses papers that only use the new one, and the reverse. If a science deck cherry-picks whichever string has a prettier abstract, that is a methods problem wearing Latin.

Identity testing has to declare which database and which name it reports. A 16S match to an old entry is not a whole-genome confirmation of a deposit. Ask for the method (draft 43).

## Practical rule for this pack

First mention: new binomial, old binomial once, strain ID if we have it, deposit if we have it. After that, strain ID or the new binomial. Never "lactobacilli" as if they were one active ingredient. Never a count of *Lactobacillus* species as a quality score.

The split is a gift to anyone who already believed Hill 2014. It makes species-level theater harder to perform with a straight face. The houses that print GG, HN019, NCFM, or a CNCM number were already doing the work. The houses that print a genus and a billion-count were already not doing it. 2020 just changed the spelling of the dodge.

## A short working table (teaching examples, not a catalog)

| Older label you still see | 2020 combination (Zheng et al.) | What did not move |
| --- | --- | --- |
| *Lactobacillus rhamnosus* | *Lacticaseibacillus rhamnosus* | Strain ID, deposit |
| *Lactobacillus casei* | *Lacticaseibacillus casei* | Strain ID, deposit |
| *Lactobacillus plantarum* | *Lactiplantibacillus plantarum* | Strain ID, deposit |
| *Lactobacillus reuteri* | *Limosilactobacillus reuteri* | Strain ID, deposit |
| *Lactobacillus brevis* | *Levilactobacillus brevis* | Strain ID, deposit |
| *Lactobacillus acidophilus* | *Lactobacillus acidophilus* | The genus stayed |

If a COA uses the left column and a paper uses the right, they may still be the same isolate. They may also be two different lines sharing a pre-2020 neighborhood. The deposit is how you tell.

## Search, citations, and the cherry-pick

PubMed after 2020 is a split brain. A deck that searches only the prettier string will find a prettier abstract. Require both strings in a substantiation folder, plus the strain ID. If the ID is missing, you do not have a folder. You have a Latin mood.

Journals still accept sloppy species-only methods. That is a journal problem. It is not permission to be sloppy on a carton. Binda 2020's deposit line exists because names move and houses swap.

## Dual naming without fog

New name, old name once in parentheses, strain ID on the same line, deposit if you have it. That is a transition sentence. "Proprietary lactobacillus blend" is not a transition sentence. It is a refusal to be checked. Draft 16 shows what a checkable line looks like. Draft 15 shows what a blend does to it.
