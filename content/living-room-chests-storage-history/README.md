# Living-room chests and storage history — BBF staged drafts

Educational essays for the BBF channel. Not a catalog. Not a showroom walk-through. Not published.

The pack teaches **boxes that hold things in the room people sit in**. The living room is a late American name. The chest is older than the name. Read `STYLE_GUIDE.md` before you edit a sentence.

## Staging

Every draft in `drafts/` is `status: staged`. Keith holds the publish pen.

| Status | Meaning |
| --- | --- |
| `staged` | Ready for Keith’s cut. |
| `hold` | Missing a fact only Keith or a catalog can supply. |
| `cut` | Parked. |
| `aired` | Used. Do not silently rewrite history. |

This landing is **44 staged essays** plus apparatus.
