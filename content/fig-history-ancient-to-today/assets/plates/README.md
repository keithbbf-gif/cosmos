# Plate redraws — graphics lane

These are **not photographs**. If you redraw Ehret, Köhler, or a syconium section, the caption must say “redrawn after…” and the license of the source plate must remain in `IMAGE_SOURCES.md`.

Suggested later files (do not create fake historical scans):

- `ehret-1771-redraw.svg` — leaf, syconium, long section
- `kohler-medicinal-redraw.svg` — flowering detail + wasp note (wasp is modern annotation)
- `bimbi-cultivar-key.svg` — key to named fruits in the 1696 Medici painting
- `tomb-offering-line.svg` — line drawing after a published Old Kingdom offering table (cite the tomb)

Until those exist, articles embed the Commons files of the original plates.
