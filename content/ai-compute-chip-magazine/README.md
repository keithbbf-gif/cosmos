This folder is a **staged magazine issue**: forty-five **standalone** articles on public GPU / CUDA / TPU history. Nothing here is cleared for a homepage or press quote.

## How to read

- Start at `INDEX.md` for the table of contents.
- Each file is one article with its own hook; cross-links are optional.
- `RIGHTS.md` documents original SVG assets (CC0) and the no–AI-art policy.
- `MANIFEST.md` lists inventory checks for reviewers.

## Image + SEO

- Series card and key hinge articles embed `<figure>` blocks with `alt`, `figcaption`, and lazy-loading attributes.
- Every numbered article (`01`–`45`) carries `description`, `image`, and `image_alt` in YAML for aggregators.
- No AI-generated imagery; diagrams are hand-authored SVG.
