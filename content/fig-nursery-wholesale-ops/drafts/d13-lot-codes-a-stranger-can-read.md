A lot code a stranger can read is the only lot code that matters in
February. I have a notebook full of codes that only I understood in
December. By the week the box comes back as a question, I am a
stranger to my own handwriting.

The code has to answer four things without me in the room:

- What name did we think this was?
- Which mother or which tote?
- What week did we cut it?
- What grade and count left the bench?

I write it like `CEL-P2-2612-STD25` — Celeste, pot/row 2, year-week,
standard twenty-five. Ugly. Readable. Not a joke acronym. Not a
QR that dies when the phone is in the truck. A QR can ride along.
It cannot be the only copy. California’s plant-board notes even
flag that some destination certificates cannot be a scanned code
**[VERIFY]** if you are in that paper world. Our shop code is
humbler. It still should print.

I put the same string on the bundle, the bag, the slip, and the
notebook line. If I invent a second string because the first one
felt long, I have two histories. Two histories is how you “fix”
a mix-up by making it untraceable.

When a buyer sends a photo, I want to see that string. Then I can
walk to the mother and look at her. Then I can say we cut that
lot on this week from this plant. Or I can say we screwed up.
Both are better than “looks like Celeste to me from here.”

I do not encode secrets. I do not hide the cut week because the
wood sat. The week is the point. If the week is old, the receiver
should know they are sticking inventory, not this-morning wood.

Keith uses the lot when he kills a name. If pot 2 fruits wrong,
every code with P2 gets a note: do not sell, watch, or relabel as
unknown. That note is worthless if the winter boxes have no P2
on them.

Keep a one-page legend on the cooler door: how to read the code.
If Jack is gone to town and I am packing, I should still be able
to finish a box without inventing a new language. If the legend
needs a meeting, the code is too clever.

People in software love unique IDs. People on a fig bench love
a string they can shout across the shop. Shout test: “Celeste
P2 week 12 standard twenty-five.” If I have to say “wait, that’s
the hash,” I overbuilt it.

The lot code will not make wood honest. It will make a lie
findable. Findable is the beginning of a nursery, not the end.

I test a new code by handing it to Keith without the legend.
If he can say the variety, the mother, and the week, it
passes. If he says “is this the hash,” I rewrite it. The
shout test is not cute. It is how a shop with two people
does not become a shop with a private language.

When a code retires — mother pulled, name killed — I do not
reuse the string that season. Reuse is how a throw note
lands on a new brick. New week, new string, old note stays
in the book. The book is allowed to be messy. The box is
not.
