# Staging sheet

Every file in `drafts/` carries YAML:

```yaml
status: staged
stage: read | fix | cover | water | pot
voice: human
focus: 8a
zones: [7, 8a, 8b, 9]
cluster: soil | drainage | mulch | irrigation | media | trouble
```

`status: staged` means the piece has had a voice pass and is waiting on a human.
It is not `published`. It is not `scratch`.

## Read order (if you want a root system, not a pile)

1. `d01` through `d10` — what the dirt is doing
2. `d11` through `d20` — how you change the hole
3. `d21` through `d28` — what you lay on top
4. `d29` through `d40` — when the hose is a tool and when it is a weapon
5. `d41` through `d48` — what belongs in a can

## Required topics (coverage)

- Soil: clay, sand, pH, compaction, tests
- Drainage: puddle test, berms, raised beds, bathtub hole, hardpan
- Mulch: chips / hay / straw, trunk clearance, fabric, rust litter
- Irrigation: first year, established, fruit swell, split, freeze water, hose chemistry
- Container media: Promix HP, perlite, coir vs #3, moisture-control bags, lift test

If a later editor cuts the set down, keep at least one draft from each stage
and do not cut `d06` (puddle test), `d13` (bathtub hole), or `d43` (Promix / field capacity).
