# Photo captions

Magazine captions (one or two sentences) plus rights. **Do not upload a file whose license row says confirm or reserved** until a rights editor signs off. Prefer Met Open Access (CC0), Smithsonian Open Access (CC0), Wikimedia public-domain files with a named museum source, and British Museum Collection Online (often CC BY-NC-SA 4.0 — not for commercial reuse without a check).

Alt text is written for a reader who cannot see the image, not as SEO stuffing.

## License key

| Code | Meaning |
| --- | --- |
| CC0 | Public domain dedication (Met OA, many SI) |
| PD | Public domain (date/author) |
| CC-BY | Attribution required |
| BM-NC | British Museum typical CC BY-NC-SA 4.0 |
| RES | Rights reserved; museum permission |
| CONF | Confirm current terms on the collection page |
