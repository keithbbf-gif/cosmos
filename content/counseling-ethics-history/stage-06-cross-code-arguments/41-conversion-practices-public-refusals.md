**Educational note.** This is history for a general reader. It is not a diagnosis, not a treatment plan, and not a substitute for care with a licensed clinician.

American psychiatry removed homosexuality from its diagnostic manual in a 1973 fight that Ronald Bayer later wrote as institutional history. Counseling and psychology and social work spent the following decades arguing about practices that claimed to change sexual orientation or gender. APA's 2009 task force report on appropriate therapeutic responses to sexual orientation is a public document. ACA published statements and, in 2014, values-and-referral sentences that later teachers read as part of the same refusal climate. NASW's nondiscrimination namings (1967, 2008) and later statements sit in the same weather.

This essay will name the refusals as historical objects. It will not teach the refused method. It will not narrate "success." Guardrails already said that. It is worth saying again in the body, because this is the essay where a reckless writer would start to describe techniques.

## What a refusal is

A refusal is not a statute. Some states later banned conversion practices for minors; some wrote conscience protections the other way. A refusal is not a trial of a named clinician. A refusal is a membership body saying, in public, that a certain advertised work is not the craft.

Bayer's 1973 story is psychiatric. Counseling inherited it. The sister pack already said so. This pack's job is narrower: the *codes and statements* are how the inheritance was written down, late and under pressure.

## 2009 as a dated APA object

The 2009 APA task force report is assigned in training programs and argued over. I will not summarize its clinical recommendations as if they were this site's. I will say it exists, it is dated, and it is one reason later readers hear "APA forbids conversion therapy" as a short sentence. Short sentences compress reports. Compression is a historical event.

## 2014 ACA as a values object, not a how-to

Draft 27 already treated the 2014 values-and-referral fight. Some of that fight was about sexual and gender minorities in the room. Some of it was about religious counselors in training programs. Courts and legislatures took pieces of the fight. This essay will not retry those cases. It will say the 2014 book is a document in a stack that also includes statements, model-rule campaigns, and state bills.

## What this page will not become

A list of techniques. A debate stage. A testimonial. A "both sides" last paragraph that reopens a method the associations have refused. A recruitment page. A service page.

If you need care, see a licensed clinician who is actually licensed for the work. If you need a statute, see a legislature or an attorney. If you need the 2009 report, see APA's page.

## Statements beside codes

Associations often refuse first in a statement, a resolution, or a task-force report, and only later, if at all, in a numbered standard. The 2009 APA report is that kind of object. ACA's public statements sit beside the 2014 values sentences. A historian who only reads the code PDF will miss the louder public refusals. A historian who only reads the statements will miss what is actually enforceable in the membership sense.

This pack keeps both objects and still refuses to describe the method that was refused.
