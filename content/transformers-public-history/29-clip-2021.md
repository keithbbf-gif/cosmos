# CLIP: contrastive language–image transformers (26 February 2021)

**Status:** staged draft. Not a publication.
**Lane:** public transformer architecture history.
**First public appearance:** 26 February 2021 (`arxiv-v1`).
**Primary source:** Radford, Kim, Hallacy, Ramesh, Goh, Agarwal, Sastry, Askell, Mishkin,
Clark, Krueger, Sutskever, *Learning Transferable Visual Models From Natural Language
Supervision*, arXiv:2103.00020.

## The claim

CLIP trains an **image encoder** (ResNet or ViT) and a **text encoder** (Transformer) with
a contrastive loss on image–text pairs, so a batch becomes a pairing problem rather than a
classifier with a fixed label set. Zero-shot ImageNet is the famous demo: class names become
text prompts. Architecturally, this is the public type-case of **two Transformers (or a
ViT and a Transformer) aligned in a shared embedding space**.

The arXiv id is 2103.00020; the export API published stamp is 2021-02-26. Use the stamp.

## What the artifact specified

Image towers: several ResNets and ViT-B/16, ViT-L/14, etc. Text tower: a 12-layer
Transformer with 512-wide type-case settings in the paper. Temperature-scaled pairwise
similarities, large batch contrastive training, WIT-style web image–text data (not fully
released). Prompt engineering and ensembling are part of the evaluation protocol, which
later papers sometimes quietly keep.

CLIP does **not** generate images. DALL·E (January 2021 blog/paper line) is a different
OpenAI system. Secondary lists that file CLIP as a generator are wrong.

## What it displaced

The closed ImageNet label set as the only way to get a transferable visual backbone.
After CLIP, "text as labels" is a default, and every later multimodal LLM that freezes a
CLIP-class encoder is borrowing this alignment, including LLaVA (17 April 2023).

## Immediate lineage

ALIGN, Florence, OpenCLIP reproductions, CLIP-guided diffusion, Flamingo (cross-attend to
a frozen visual encoder, 29 April 2022), BLIP / BLIP-2, LLaVA. The *projector plus frozen
vision encoder plus frozen or tuned LM* pattern is 2022–2023; CLIP is the vision-text
anchor.

## What this draft does not claim

It does not claim the WIT dataset is fully specified for bit-identical replay. It does not
treat later "CLIP embeddings" in products as this paper's weights. No private contrastive
stack is described.
