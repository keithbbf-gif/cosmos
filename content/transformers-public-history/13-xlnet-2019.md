# XLNet: permutation language modeling on a Transformer-XL (19 June 2019)

**Status:** staged draft. Not a publication.
**Lane:** public transformer architecture history.
**First public appearance:** 19 June 2019 (`arxiv-v1`).
**Primary source:** Yang, Dai, Yang, Carbonell, Salakhutdinov, Le, *XLNet: Generalized
Autoregressive Pretraining for Language Understanding*, arXiv:1906.08237.

## The claim

BERT's mask token is a pre-train / fine-tune discrepancy: the model sees `[MASK]` in training
and not at most fine-tune times. XLNet proposes to keep an **auto-regressive** factorization
(no mask token) while still letting each position learn from both sides, by training on
**many permutations** of the factorization order and by using a two-stream attention
construction so the query at position \(i\) does not trivially see token \(i\).

The backbone is Transformer-XL, not a vanilla BERT encoder. That is an architecture fact, not
a footnote.

## What the artifact specified

Permutation language modeling: sample a factorization order, predict token \(x_{z_t}\) given
the previous tokens in that order. Two-stream (content and query) attention implements the
"you may use position \(i\)'s slot without using token \(i\)'s identity" constraint. Segment
recurrence and relative encodings come along from Transformer-XL.

They report then-SOTA on GLUE, SQuAD, RACE, and several other suites, at BERT-Large-comparable
and larger sizes. Author-reported 2019 numbers, widely re-discussed when RoBERTa later matched
or beat them with a simpler objective and more compute.

## What it displaced

A brief public consensus that BERT's MLM was the only way to get bidirectional context into a
Transformer encoder. XLNet showed a different objective could work. It did **not** displace
BERT as the default starting point; the two-stream machinery was heavier to implement, and
RoBERTa's "same objective, better recipe" story was easier to copy.

## Immediate lineage

The lasting architectural export is smaller than the 2019 hype: relative + segment memory
stayed visible; permutation LM did not become the 2023 LLM default. T5's text-to-text MLM-like
corruption and later UL2's mixture of denoisers are the objective-family continuation, not
permutation LM specifically.

Use this card as a warning about **objective vs block**. XLNet changed both. Popular memory
keeps only the leaderboard.

## What this draft does not claim

It does not claim XLNet "won" BERT. It does not reconstruct two-stream attention as a 2024
serving trick. It does not treat later decoder-only models as secret XLNets.
