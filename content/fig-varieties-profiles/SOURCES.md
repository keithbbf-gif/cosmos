# Research notepad — variety profiles

Working notes behind `BIBLIOGRAPHY.md`. Not for WordPress.

## Type words we will not blur

- **Common / persistent:** sets without a wasp. Almost everything we tell an Arkansas neighbor to plant.
- **Smyrna / caducous:** drops unless caprified. Calimyrna / Sari Lop. Not a backyard project in 8a.
- **San Pedro:** breba persistent; main crop often needs pollen. Desert King / King. Explain. Do not sell it as a “common fig that fruits twice.”
- **Caprifig:** pollen source. Jack already said a few taste fine and most do not.

## Name piles that wreck threads

- Brown Turkey / Eastern Brown Turkey / Texas Everbearing / Harrison ≠ California Brown Turkey / San Piero / Black Spanish.
- Celeste / Malta / Celestial / Sugar Fig / Little Brown Sugar. Condit preferred Malta. Nobody in a Southern yard says Malta.
- Improved Celeste / O’Rourke / ICON. Official LSU release is O’Rourke. A lot of “Improved Celeste” in the trade is something else.
- LSU Gold *is* an official release (LSU 2025 history). Older Alabama “rumored / never released” language is stale.
- Panache / Tiger (the chimera) ≠ LSU Tiger.
- Violette de Bordeaux / Negronne. Beer’s Black is a different argument. Do not merge them to win a sentence.
- Lattarula / Peter’s Honey / Italian Honey / Blanche / White Marseilles. Alabama reserves judgment. Condit folded some of these. Taste the tree.
- Verte / Green Ischia / Coeur. Keith already said Verte splits on us. Do not write it as a clean synonym until fruit matches.
