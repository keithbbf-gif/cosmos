# Furniture Hardware History

Draft series. Not published copy. Hinges, pulls, locks — the metal that lets furniture work, and the metal that tells you when it was made.

The pieces live in `drafts/`. They are stage-3 drafts: researched, outlined, then written in a human voice. They are not encyclopedia entries and they are not product copy. Each one argues something small and specific.

## How to read this

Start with `STAGE.md` if you want the method. Start with `drafts/01-the-thing-you-never-look-at.md` if you want the series.

Cluster order is not the only order. The opener, the screw essay, and the empty-hole essay talk to each other. The lock race and Yale essays talk to each other. The Blum essay is late on purpose: most kitchens now live after it.

## Counts

- Stage 1 research notes: `research/`
- Stage 2 outlines: `outlines/_index.md` (45)
- Stage 3 drafts: `drafts/` (45)
- This folder is staged work. Nothing here is a live-tree claim.

## Voice

First person where it helps. Shop floor, not seminar. Dates when a source holds them. Hedged when sources disagree. No invented quotations. No museum accession numbers I did not look up. Replacement hardware is treated as the first dating trap, not a footnote.

## What this is not

Not a catalog. Not a buying guide. Not a restoration manual that tells you to polish everything bright. Not COSMOS documentation.
