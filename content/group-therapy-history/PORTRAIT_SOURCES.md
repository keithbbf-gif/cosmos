# Portrait sources — licenses, or an honest blank

**Rule.** Public domain or Creative Commons only. Never generate a face. Never crop a still from a documentary you do not have rights to. Never use a university or AGPA "headshot" page as if it were free.

Graphics agents: read this file before drawing. If `status` is `no-portrait`, set type (name, dates, one object) or a **period object** listed below. Do not "fill in" a likeness.

Last verified against Commons/museum pages: 2026-09-14. **Re-open the file page on upload day.** Licenses get edited.

## Status key

| Status | Meaning |
| --- | --- |
| `pd` | Use. Copy license line under the image. |
| `cc` | Use. Keep BY/SA text. |
| `confirm` | Commons *claims* PD/CC; author unknown or US status thin. Do not use as a featured image until a human re-reads the file page. |
| `no-portrait` | No clean still of the person. Type or period object only. |
