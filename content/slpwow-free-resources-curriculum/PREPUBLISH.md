# SLPWOW Free PDF — Prepublish checklist

**Status:** gate. A page does not ship until every box is honest.
**Authority:** `CLAIMS_GUARDRAILS.md` wins ties.

Use this on the ticket for each SKU. Writer completes. Reviewer initials. A refuse is a correct outcome.

## 1. Identity

- [ ] SKU matches `FORMAT_SCOPE.md` §7: `SLPWOW-FR-{FORMAT}-{DOMAIN}-{BAND}-{NN}`
- [ ] Filename matches SKU
- [ ] Title names a **practice job** or a **shell**, not a disorder
- [ ] Design band from `AGE_BANDS.md` is printed as a *feel*, not a cutoff
- [ ] PDF document title / subject say it is not an evaluation

## 2. Claims (refuse on any miss)

- [ ] Canonical footer from `CLAIMS_GUARDRAILS.md` §4 is on page 1, ≥ 8 pt
- [ ] Report templates add the PHI / storage sentences
- [ ] `FLU` / voice pages add the domain sentence
- [ ] No diagnose / screen / detect / rule-out language
- [ ] No percentile, standard score, age-equivalent, or printed severity
- [ ] No “will improve,” “fixes,” “cures,” “guaranteed”
- [ ] No “evidence-based” / “ASHA-approved” badge
- [ ] No eligibility / IEP qualification language
- [ ] No referral rule tied to a tally (“if < 4, evaluate”)
- [ ] Age band is not a mastery table

## 3. Originality (refuse on any miss)

- [ ] I did not retype, close-paraphrase, or redraw a page from the web, a marketplace, or a publisher
- [ ] Word lists were compiled here from ordinary English (or from our seeds in `briefs/word-lists.md`)
- [ ] No trademarked characters, no “inspired by” clones
- [ ] Art is ours or licensed for free redistribution
- [ ] Fonts may be embedded in a free PDF
- [ ] I can name who wrote the sentences and when

If a sentence came from a tab you cannot remember, delete the sentence.

## 4. Format fit

- [ ] `WS` — trial sheet + data strip; not a test
- [ ] `PO` — reference/setup; no quota calendar
- [ ] `WL` — 12–24 words or a handful of frames; clinician-facing; blanks
- [ ] `RT` — empty shell; no canned diagnosis; fictional samples only

## 5. Style and use

- [ ] US Letter, black-and-white first, margins ≥ 0.6 in
- [ ] Clinician voice is adult and specific
- [ ] Student voice matches the band (`AD`/`AX` are not cartooned)
- [ ] Data boxes are pen-sized; no auto-severity
- [ ] Meaning does not depend on color
- [ ] Photocopy check done (or queued with a named person)
- [ ] Send-home is a clinician choice, not a default demand

## 6. Domain extras

- [ ] `ART`/`PHN` — clinician names the target; no mastery age
- [ ] `VOC`/`SYN`/`NAR` — no MLU / “below average”
- [ ] `PA` — not a dyslexia or readiness screen
- [ ] `SOC` — skip any; no eye-contact rubric
- [ ] `FLU` — no smoothness prize; no “slow down” student order
- [ ] `AAC` — blanks; does not measure cognition
- [ ] Swallow / medical voice treatment — **not in the file**

## 7. Sign-off

```
SKU: ______________________________
Writer: ____________  date: ________
Reviewer: __________  date: ________
Verdict:  ship  /  refuse
Refuse reason (file + line + fix):
____________________________________
```

Do not ship on writer-only sign-off. One other pair of eyes. If the second person is the same as the first, it is not a review.
