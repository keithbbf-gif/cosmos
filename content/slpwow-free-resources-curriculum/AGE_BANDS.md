# SLPWOW Age Bands

**Status:** design targets for the free curriculum.
**Authority:** `CLAIMS_GUARDRAILS.md` §5. This file does not publish developmental norms.

Age bands tell a writer how dense a page can be, how large the type should be, what kind of pictures fit, and which everyday words are fair game. They do **not** tell a clinician that a person is delayed, advanced, or “typical.”

A clinician may take a preschool page into a middle-school session, or the reverse, if the target fits. The band is a **starting cut**, not a gate.

## 1. Band table

| Code | Name | Chronological design window | School-ish shorthand | Page density | Default type |
|---|---|---|---|---|---|
| `EI` | Early interaction | 18–35 months | toddlers / early intervention | one idea, huge pictures, almost no independent writing | 18–22 pt student marks; clinician text 11–12 pt |
| `PK` | Preschool | 3;0–5;11 | preschool / Pre-K | 4–6 pictures or 4–6 spoken items | 16–18 pt |
| `EE` | Early elementary | 5;0–8;11 | K–2 | 8–12 items; optional tracing | 14–16 pt |
| `LE` | Late elementary | 8;0–11;11 | grades 3–5 | 12–20 items; short written response OK | 12–14 pt |
| `AD` | Adolescent | 12;0–17;11 | middle / high school | text-forward, low “little kid” art | 12–13 pt |
| `AX` | Adult / transition | 18+ | adult outpatient, vocational, campus | adult register, no cartoon mascots | 12–13 pt |
| `MX` | Mixed / clinician-cut | any | groups, siblings, unknown age | extra white space; clinician crosses out | 14 pt |

Overlaps (5;0–5;11 sits in both `PK` and `EE`) are **intentional**. Kindergarten is not one developmental number. The writer picks the **page feel**, then prints both codes on the SKU if needed (`PK/EE`).

Do not invent extra bands (`K-only`, `grade 4 gifted`) in the free line. If a page is truly grade-locked, you are writing a school worksheet, not an SLPWOW practice page — revisit the brief.

## 2. What a band changes (and what it must not)

**A band may change:**

- picture count and visual clutter
- whether the student writes, marks, points, or only talks
- vocabulary register (playground vs. hallway vs. workplace)
- length of spoken models the clinician is asked to read
- how much “cute” is allowed (adolescents get none unless they ask)

**A band must not change:**

- whether the page diagnoses
- whether a tally becomes a standard score
- whether a missed item becomes a referral rule
- whether we print “mastery age for /s/”

If you need a reminder about typical sound acquisition, keep it in an **internal** team note with a source the team actually opened. **Do not print mastery ages on the PDF.** See `CLAIMS_GUARDRAILS.md` §5.

## 3. Band-by-band production notes

### `EI` — Early interaction (18–35 months)

**Use for:** caregiver-and-clinician pages, one-picture choice, gesture + word, joint attention setups.

**Student page:** one photograph-style or simple object picture. One printed word the adult says. No “circle four.” No mazes. No stickers-as-data.

**Clinician / caregiver strip:** two or three *optional* things to try (“name it,” “wait,” “offer a choice”). No “say it or else.”

**Out of band:** independent worksheets, homework packets with 20 trials, anything that requires a toddler to hold a pencil for data.

**Claims:** this is play-adjacent practice. Never “early intervention evaluation form.”

### `PK` — Preschool (3;0–5;11)

**Use for:** picture choice, repetition after a model, simple category sort (2 piles), short verbal fill-in.

**Student page:** 4–6 large pictures. Thick mark boxes. Color optional; design in black-and-white first.

**Language:** short, concrete. Avoid idiom-only items.

**Out of band:** paragraph reading, “write a sentence,” timed fluency contests.

### `EE` — Early elementary (5;0–8;11)

**Use for:** the default free-line worksheet. Word + picture, 8–12 trials, a small data strip.

**Student page:** can include tracing or copying a model word *if* the target is speech or language, not handwriting instruction. Do not become a handwriting curriculum.

**Watch:** first-grade pages that accidentally become reading tests. If the item cannot be done from a picture + clinician model, it is too print-heavy.

### `LE` — Late elementary (8;0–11;11)

**Use for:** sentence-level practice, short written responses, self-rating *of the task* (“this one felt easy / okay / hard”) — never a self-diagnosis.

**Student page:** fewer baby pictures. Real-object or simple line art. Humor is allowed if it is kind.

**Watch:** “mad libs” that force a disorder joke.

### `AD` — Adolescent (12;0–17;11)

**Use for:** interview prompts, classroom-language frames, self-advocacy *scripts the student may refuse*, workplace/classroom word lists.

**Student page:** looks like a one-pager a teen would not hide. No stars, no cartoon animals, no “super speech hero.”

**Watch:** social pages that police personality. Offer AAC / typed / spoken options on every prompt.

### `AX` — Adult / transition (18+)

**Use for:** adult outpatient practice, campus communication, vocational role-play frames, caregiver pages for adult clients.

**Register:** adult. “Client” is fine. “Kiddo” is not.

**Watch:** stroke / aphasia / cognitive pages that pretend to be screens. Free line stays at **practice frames and blank snapshots**, not cognitive tests.

### `MX` — Mixed

**Use for:** group rooms, unknown-age downloads, sibling sessions.

**Rule:** every item is strikeable. Print “clinician crosses out what does not fit” under the title.

## 4. How to print the band on a PDF

Header line, clinician type (11–12 pt):

```
SLPWOW-FR-WS-ART-EE-01    ·    Speech-sound practice    ·    Design band: EE (K–2 feel)
```

Do **not** print:

```
For ages 5–8 only    ·    If older, the child is delayed
```

Secondary line allowed:

```
Clinician may move this page up or down a band.
```

## 5. Choosing a band when the writer is unsure

1. If the student must **decode connected text** to do the item → at least `LE`, or add pictures and drop to `EE`.
2. If the page needs a **caregiver’s body** in the activity → `EI` or `PK`, and say so.
3. If the art would embarrass a 13-year-old → it is not `AD`.
4. If you want one PDF for “everyone” → `MX`, and accept a shorter item list.
5. If the only reason for a band is “so we can say they failed the age” → **stop**. That is a screen. See `CLAIMS_GUARDRAILS.md` §2.

## 6. Groups and mixed caseloads

Free PDFs do not solve mixed groups by printing three difficulty ribbons that look like test levels.

Allowed:

- the same picture with a clinician note: “imitate / choose / use in a sentence”
- a second page of *more* items, not “Level 1 / Level 2 / Level 3” branded as ability

Forbidden:

- bronze / silver / gold “speech levels”
- “pre-emergent / disordered / typical” rows

## 7. Chronological age as a *field*, never a *result*

Report templates and data strips may have:

```
Chronological age (clinician writes): ________
```

They may not have:

```
Developmental age: ________     Gap: ________
```

A gap field is a back-door diagnosis.

## 8. Crosswalk for first-wave SKUs

Use one primary band per SKU. If a page is truly dual-feel, the SKU may show two codes (`PK-EE`) and the header must say “design feel: preschool or early elementary — clinician picks.”

| First-wave default | Band |
|---|---|
| Caregiver carryover, one picture | `EI` or `PK` |
| Articulation / pattern practice worksheets | `EE` (adapt notes for `PK` and `LE`) |
| Word lists (clinician book) | `MX` with register tags per list |
| Classroom language frames | `LE` or `AD` |
| Session snapshot / report shells | `MX` (the form is for the clinician, not the child) |
