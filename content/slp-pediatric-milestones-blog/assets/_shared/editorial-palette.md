# Editorial palette — SLPWOW pediatric milestones (figures)

Use consistently across SVG figures in this pack.

| Role | Hex | Usage |
|------|-----|--------|
| Canvas | `#FAF9F7` | Figure background |
| Ink | `#1E293B` | Primary labels, axes |
| Muted ink | `#64748B` | Secondary labels, grid |
| Rule | `#CBD5E1` | Grid lines, dividers |
| Clinical teal | `#0F766E` | Primary emphasis, “talk with a clinician” |
| Warm milestone | `#C2410C` | Age-band anchors (not alarm red) |
| Soft fill | `#E2E8F0` | Bands, regions |
| Listening fill | `#CCFBF1` | Understanding / receptive emphasis |
| Speaking fill | `#E0E7FF` | Expressive / output emphasis |

**Type (SVG):** Labels `system-ui, sans-serif` 11–13px; titles Georgia or `serif` 14–18px semibold.  
**Stroke:** 1px rules; 2px timeline spine; rounded rects `rx="4"`.

**Claims:** Captions must say *schematic*, *most children*, *conversation starter*, or *not a diagnosis* where the figure touches milestones or referrals.
