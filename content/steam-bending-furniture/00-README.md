# Steam bending — history and shop practice

Staged drafts for Bradley Brand Furniture (BBF). Warren / Wilmar, Bradley County, Arkansas.

This folder is a writing room, not a dump. Files are numbered in the order they were made. Later files argue with earlier ones. The piece that can leave the room is `42-longform-final.md`. The wall card that can hang by the box is `41-shop-wall-short.md`.

Read in order if you want the work. Skip to 41 and 42 if you only want the finished mouths.

## House rules for this folder

- Human voice. Shop first. Catalog last.
- A number has a source or it stays out.
- BBF is a hardwood shop in a mill town. It is not Gebrüder Thonet. Do not write it as if it were.
- Do not invent a steam line we did not run. Practice here is what the shop *would* do, and what the Forest Service and the chairmakers already measured.
- History is not decoration. It is how you know which trick is old and which trick is a catalog lie.
