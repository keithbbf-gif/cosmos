# Wow Therapies — Therapy History (content)

Editorial graphics and embed-ready figures for the therapy-history strand. **Publishable
artifacts live under `staged/` only** until a release pass moves them forward.

| Path | Role |
|------|------|
| `GRAPHICS_INDEX.md` | Canonical figure register (IDs, captions, credits, status) |
| `staged/graphics/` | SVG figures (magazine layout) |
| `staged/EMBEDS.md` | Copy-paste embed blocks + captions for CMS |
| `pipeline/` | Seeding, validation, portrait-source registry |
| `drafts/` | Sparse notes only — run pipeline to refresh core figures |

**Portrait policy:** plates never ship AI-generated or invented historical faces. Plates
use typographic monograms until a verified public-domain (or licensed) photograph is
embedded and credited per `pipeline/portrait_sources.yaml`.
