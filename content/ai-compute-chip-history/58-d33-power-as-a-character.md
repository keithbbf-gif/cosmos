# Draft 33 — power as a character, one scene

Job: write the watts so they change a picture, then refuse a
second scene. The final only needs one.

v1 TPU: you could, if you were being a little cute, talk about
it the way you talk about a disk. Tens of watts. A slot that
already existed. The point of that picture is not thrift as a
virtue. The point is *sneaking a specialist into a building
without asking the building to become a different building.*

V100, H100: the card is now a space heater with a firmware
team. You plan the empty slot next to it. You plan the PSU.
You still, just barely, plan a fan.

Blackwell-class racks and Ironwood-class pods: the building
is the chassis. Liquid is not an enthusiast extra. Google's
own Ironwood writing mentions pods on the order of 10
megawatts. You do not need the exact number to feel the
change. You need to feel that the disk-bay trick is over.

The character arc is not "we use too much electricity," which
is a different piece and a true one. The arc is: **the package
that holds the loop outgrew the machine you already owned.**
1999–2015 is "put it in a PC, then a server." 2024–2026 is
"pour a slab and file with the county."

One paragraph in Groceries is enough. If it grows, it is
preaching.
