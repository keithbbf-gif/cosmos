# Public timeline (checked)

Dates a reader can trust enough to learn from. Peak-FLOPS claims
are marked as vendor-peak. When two official sources disagree, both
are listed.

| When | What | Why it is in the essay |
| --- | --- | --- |
| 1993-04-05 | NVIDIA founded (Huang, Malachowsky, Priem) | The company that later names the era starts as a 3D graphics shop. |
| 1999-08-31 / 1999-10-11 | GeForce 256 announced / ships | NVIDIA popularizes "GPU" as a single chip with T&L + render. |
| 2004 | Ian Buck finishes Stanford Brook work, joins NVIDIA | The GPGPU research line walks into the vendor. |
| 2006 | AMD acquires ATI | The other GPU house gets a parent with CPUs. |
| 2006-11-08 | CUDA unveiled with GeForce 8800 (Tesla architecture) | C on the GPU, publicly. |
| 2007 | Tesla-branded compute boards | GPU as a rack citizen, not only a monitor's friend. |
| 2008 | OpenCL 1.0 (Khronos) | The portable alternative. |
| 2009 | Raina, Madhavan, Ng — large deep models on GPUs (ICML) | Academic proof before the contest. |
| 2012 | AlexNet on 2× GTX 580 3 GB; ILSVRC win | The hinge. 5–6 days, ~90 epochs, 1.2M images. |
| 2012 | DistBelief / large CPU-cluster training (incl. the "cat" work on ~16k cores) | Same year, the other machine. |
| 2013–14 | Caffe; Google starts TPU work (publicly recalled as a 2013 need) | Layers as a language; an ASIC gets a reason. |
| 2014-09 | cuDNN announced | Deep learning gets its BLAS. |
| 2015 | TPU v1 in Google datacenters (per 2017 paper) | Inference ASIC in production before the keynote. |
| 2015-11 | TensorFlow open-sourced | Python meets CUDA for a mass audience. |
| 2016-05 | TPU announced at Google I/O | The public name. |
| 2016 | PyTorch appears; Pascal P100 / NVLink | The research default starts to form; HBM + NVLink in NVIDIA's line. |
| 2017-05 | TPU v2 (training, bfloat16, Cloud TPU); Volta V100 + Tensor Cores (May 10) | Two answers to the same matrix. |
| 2017 | "Attention Is All You Need" trained on 8× P100 | Transformer is born on GPUs. |
| 2017 | Jouppi et al., ISCA — TPU v1 paper | 92 TOPS, 256×256 array, 15–30× vs K80/Haswell on their inference mix. |
| 2018-05 | TPU v3 | Bigger chips, bigger pods. |
| 2018 | Turing; Edge TPU / Coral later in 2018–19 | Tensor Cores go wider; a tiny TPU for the edge. |
| 2020 | Ampere A100 | The rented default of the early LLM era. |
| 2021-05 | TPU v4 discussed at I/O | 4096-chip pods in the public pitch. |
| 2022 | Hopper H100; ChatGPT in November | The card and the product that made civilians care. |
| 2023 | H200; TPU v5e GA (Nov 8); TPU v5p announced (Dec 6) | Memory-fatter Hopper; Google splits cheap vs big. |
| 2023–24 | AMD Instinct MI300X in the conversation | 192 GB as a public argument. |
| 2024-05 | Trillium (TPU v6e) at I/O | 4.7× vs v5e in Google's claim. |
| 2024 | Blackwell announced; first systems into 2025 | Two-die GPU; rack-scale NVL72. |
| 2025-04-09 | Ironwood (TPU v7) | Inference-first TPU, 192 GB, 9216-chip pod pitch. |
| 2025-06 | AMD MI350/MI355X public product pages | 288 GB HBM3E class. |
| 2026-01 | NVIDIA Rubin platform at CES | Six-chip platform; partner hardware slated H2 2026. |
| 2026-04-22 | TPU 8t and 8i at Cloud Next | Training/inference split made explicit. |

Not on this table, on purpose: unannounced dies, leaked slides,
private benchmarks.
