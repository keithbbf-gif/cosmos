# Adaptogens: history, with the claims fence up

Forty-plus **draft essays** on how a mid-century laboratory word met much
older plant practices — and how easily that meeting turns into a disease
claim if nobody watches the language.

This is educational ethnobotany and intellectual history. It is **not** a
protocol, a shop, or a list of cures.

## Read this first

1. [`GUARDRAILS.md`](GUARDRAILS.md) — what a sentence may and may not do.
2. [`CITATIONS.md`](CITATIONS.md) — named public documents and the honesty
   rule for secondary literature.
3. This index — one-line theses, in stage order.
4. Any single draft. They stand alone. They do not stack into a treatment.

If you only open one file besides the guardrails, open
[`stage-01-how-to-read/01-what-this-folder-refuses.md`](stage-01-how-to-read/01-what-this-folder-refuses.md).

## Voice and status

Human essay voice. `status: draft` and `voice_check: edited` on every essay file
after the 2026-09-14 editor pass (see [`EDITOR_REPORT.md`](EDITOR_REPORT.md)).
The series is **staged**
(six argument stages) and **git-staged** as a proposal, not published as
canon and not wired into COSMOS Core.

## Tools

```text
python3 content/adaptogens-history-claims-guarded/tools/lint_claims.py
```

The linter checks count (≥40), frontmatter, word floor, uniqueness, the
Claims box, and a list of forbidden disease-claim and bot-voice patterns.
It does not certify truth. It certifies that the fence is still standing
in the places a machine can see.

`MANIFEST.toml` is generated from frontmatter. Do not hand-edit it; rerun
the linter with `--write-manifest`.
