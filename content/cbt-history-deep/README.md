# WOW Therapies — CBT history deepen (Beck, Ellis, waves)

Staged educational pack for [WOWTherapies.com](https://wowtherapies.com). **Do not write these files onto the live site from this folder.**

Forty-four publishable drafts that **deepen** the cognitive-behavioral lane already sketched in `content/wowtherapies-therapy-history/` (especially the cognitive-turn era, the third-wave era, and the Beck / Ellis / Linehan figures). This folder is not a second general history of psychotherapy. It is the Penn notes, the East 65th Street institute, the manuals, the graphs, the nickname "third wave," and the arguments those objects started.

Complementary to the SLPWOW speech-pathology pack — not a duplicate.
