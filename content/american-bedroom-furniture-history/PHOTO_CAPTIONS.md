# Photo captions

Magazine captions live in each essay’s `## Figure plan`. This file is the rights register and the license key. **Do not upload a file whose license row says CONF or RES** until a rights editor signs off.

Prefer Met Open Access (CC0), Smithsonian Open Access (CC0), Wikimedia public-domain files with a named museum source, and collection pages whose current terms have been checked on the day of layout.

BBF shop photographs (`D:\BBF\BBF Photos`) are fills for chapters 36, 42, 43, and 45 only. Credit only what metadata supports. Photographer unnamed until file metadata is pulled.

## License key

| Code | Meaning |
| --- | --- |
| CC0 | Public domain dedication (Met OA, many SI) |
| PD | Public domain (date/author) |
| CC-BY | Attribution required |
| RES | Rights reserved; museum or house permission |
| CONF | Confirm current terms on the collection page |
| OWNER | Keith BBF shop library — owner clearance; not a public-domain claim |
