# MESH ADDITIONS — G46 scout return (Grok Build)

**Scout:** G46 (Grok Build), mesh-expansion. **Date:** 2026-08-25.
**Consumer:** COSMOS / COW. COW verifies each row has real hands before promoting
into `docs/MESH_ADDITIONS.md`. This file is a **candidate backlog**, not a
promotion and not a claim that any of these are live on the mesh.

**Filter:** a chatbot with no hands is rejected. Every row below can **do**
something: click, fetch, edit, sync, scrape, compile, transcribe, search,
dispatch a workflow, or drive a signed-in surface.

**Rank key:** FREE + high-power first. `POWER` = new capability × reliability ×
how many COSMOS rails/surfaces it unlocks. `COST` = free / prepaid / metered /
paid. Equal power, cheaper wins.

**How COSMOS would reach it (the reach column):** COSMOS Core remains the sole
authority. Candidates are reached as **native workers** (Job-Object-contained,
attempt-private workspace, fenced commit), **MCP clients** (stdio/HTTP into a
server; today `cosmos_mcp` *exposes* Core — a consumer adapter is the missing
piece), **DOM workers** (existing `cosmos_browser` rail / Playwright / CDP), or
**HTTP APIs** through the spend gate. No candidate becomes a second ledger
writer.

(`grok -p`), four live model rails (`sgh-api` / `gem-api` / `gw-api` /
`oa-api`), COSMOS-as-MCP (`cosmos_mcp`), Chrome `--dump-dom` (`cosmos_browser`),
BTS filesystem MCP, GDX/DriveFS, Tailscale (`cosmos up`), Cursor Cloud Agent
(maker), GrokBot team (maker), scheduled-task maker. GitLab CI via `glab` is
**planned, not wired**.

## Reach patterns (how a row becomes a COSMOS hand)

| pattern | when | COSMOS binding |
|---------|------|----------------|
| **Native CLI worker** | The tool is a binary (`glab`, `rclone`, `ffmpeg`, `opencode`, `aider`) | Runner starts it in an attempt-private workspace under a Job Object; publishes **only** through the fenced commit gateway. Ledger event names the binary + argv hash. |
| **MCP-client worker** | The tool is an MCP server (Playwright, Serena, Drive, n8n, Context7) | New Core module: MCP client, stdio or Streamable HTTP. Tool calls are ledgered. `cosmos_mcp` stays the **server** face (KDash/Claude/Grok talk *to* COSMOS); this is the **client** face (COSMOS talks *out*). |
| **DOM worker** | The job is a website with no API, or the API is dead | Existing DOM rail. Prefer Playwright MCP (a11y tree) or Chrome DevTools MCP (live Chrome). Browser Use local for open-ended “figure it out.” Cloud browser-use: **no** (trains on inputs). |
| **HTTP API + spend gate** | Vendor quota/money is involved (Firecrawl paid tools, Graph send-mail) | Same path as `sgh-api` / `gem-api`: reserve → call → settle. Free/keyless tools still go through the gate with cost=0 so the ledger sees them. |
| **Sidecar** (n8n, Ollama, ComfyUI, rclone rcd, Bifrost, Crawl4AI, LibreTranslate, OmniRoute, ArchiveBox, Paperless-ngx, FreshRSS, LanguageTool, Recoll, FunASR, Datasette, DuckDB-quack) | Long-lived process, not per-job | Registered in the worker registry + prober. Dead sidecar = `UNREACHABLE`, never a silent skip. |
