# G47

Snapshot of main `501fdee25a581648ee0ddb096bdafa70a2325a71`.

## What it is

One planner for a COSMOS or COSMOS CODE harness call. A legend (role, pin, mission, window) and a door name become a pack, an argv or a rail payload, and a size. `plan` prints JSON and does not spawn.

`execute` is a separate function. It still does not start `grok.exe`: that door raises `GROK_NOT_A_WORKER` before a process exists. The cosmos-code door raises `EXECUTE_IS_RAIL`. An unseated door raises `UNSEATED`. There is no fallback model and no retry that clears a failed grade.

Size is `margin = 0.20 × window`, then `MAX = window − cached_tokens − prompt_tokens − margin`. OPTIMUM is a positive aim clamped to MAX, or the string `float`. `approx_tokens` is `len // 4` and stays an estimate until the caller passes a real count. `MAX ≤ 0` is `MAX_LE_ZERO`. Grok also refuses input over its 200k keep-under.

## Where it lives

`harness/G47/`. Package name `g47` (version 0.2.0). Design notes are `ARCHITECTURE.md` and `CODE.md`. The catalog reader is `g47/locate.py`. `installs/DOORS.toml` is the committed name list. `installs/LOCAL.toml` is this machine, written by `locate`, and is not on main.

## Entry points

- `py -3.14 -m g47 plan ...` — JSON plan. Does not spawn.
- `py -3.14 -m g47 grade --role ... --mouth -` — exits 2 when the mouth fails its contract.
- `py -3.14 -m g47 doctor` — which seated doors have a binary. Does not run them.
- `py -3.14 -m g47 locate` — writes this machine's `LOCAL.toml`. Does not download binaries.
- `py -3.14 -m g47 seat ...` — public seat record. Does not start a provider.
- Library: `plan`, `grade`, `seat`, `classify`, `prepare`, `run`.

`catalog()` returns `[]` when `installs/DOORS.toml` is absent. An empty list is not a pass.

## What it refuses

`Refuse(reason, detail)`. Reasons in this package include `UNKNOWN_DOOR`, `FORBID_FLAG`, `ARGV_TOO_LONG` (joined argv over 7000 characters), `PACK_INCOMPLETE`, `DAEMON_NOT_LLM`, `CCR_NOT_A_DOOR`, `ORC_NO_CODING`, `NO_CONTEXT` (a joined ` · ` string is not a path list), `POINTER_IN_TASK`, `EMPTY_HOUSE`, `PREFIX_VOLATILE`, `PREFILL_NOT_THIS_DOOR`, `SKILL_BODY`, `NOT_A_PIN`, `FLOOR_ON_FREE`, `SLUG_DEAD`, `WRONG_VIA`, `MIXED_VIA`, `HARNESS_GATE`, `WINDOW_UNMEASURED`, `BAD_TOKEN_COUNT`, `KEEP_UNDER`, `MAX_LE_ZERO`, `OPTIMUM_ZERO`, `LIVE_TREE`, `PATH_ESCAPE`, `GROK_NOT_A_WORKER`, `EXECUTE_IS_RAIL`, `UNSEATED`, `NO_BINARY`, and `NO_KEY`.

Forbidden flags include Codex `--ignore-user-config`, `--full-auto`, and `--danger-full-access`; Claude `--fallback-model` and `--dangerously-skip-permissions`; grok `--single`; vertex `--harness`. A positional prompt over 1200 characters becomes "Read TASK.md…". The mission stays on disk. `execute` passes `stdin=DEVNULL`.

`classify()` never sets `retry_same` true. HTTP 200 is not a seat. `process_observation` returns `seated: false`.

## What it is not

Not the harness loop (`cosmos_harness`). Not the propose rail (`cosmos_code`). Not Core, not the authority ledger, and not the CCr pen. Not a downloader. Not wipe-proof. Materialize refuses a worktree whose path is `live`. It does not upload a trace. A written pack file is not a pass.

Doors recorded as unseated: `claude`, `hermes`, `antigravity`, `none`. Aliases: `deepseek` to `dsh`, `openai` to `codex`, `gemini` to `vertex`, `ling` to `opencode`, `glm` to `pi`.
