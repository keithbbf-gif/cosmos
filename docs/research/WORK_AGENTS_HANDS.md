## What “Work” means in this class

Three different meanings of “work,” do not collapse them:

| Meaning | What the agent actually does | Typical SKU |
|---------|------------------------------|-------------|
| **Finished artifacts** | Decks, sheets, docs, Sites / hosted pages, reports — reviewable files | ChatGPT Work, Manus |
| **Local folder grants** | Reads/writes folders you connect on the machine; optional computer use | Claude Cowork (desktop), ChatGPT Work local, Gemini Spark macOS, Microsoft Scout |
| **Suite / Graph work** | Acts inside M365 or Google Workspace (mail, calendar, Drive, Teams/Chat) | Copilot Cowork, Workspace Studio, Work IQ (see MICROSOFT_COPILOT_HANDS) |

A product can mix all three. COSMOS care: **folder grants and computer use are pen-adjacent.** An orchestrator-profile occupant that receives a folder grant on `V:\A` is a second writer unless mailbox + lease (AGENT_BOUNDARIES item 9) come first.
